# Öffentliche Teilnahme

Die Funktion der öffentlichen Teilnahme ermöglicht es Projektteilnehmern, ihre Reiseinformationen und CO2-Fußabdruck-Daten über ein einfaches, zugängliches Formular einzureichen.

## Wie es funktioniert

1. Projektorganisatoren erstellen ein Projekt
2. Ein eindeutiger Teilnahmelink wird generiert
3. Teilnehmer besuchen den Link und füllen das Formular aus
4. Daten werden automatisch mit dem Projekt verbunden
5. Organisatoren können Einreichungen in Echtzeit anzeigen

## Teilnahmeformular

Das Teilnahmeformular sammelt:

### Persönliche Informationen

- Name
- E-Mail-Adresse
- Herkunftsland

### Reiseinformationen

- Transportmittel (Flugzeug, Zug, Bus, Auto)
- Abreiseort
- Ankunftsort
- Zurückgelegte Entfernung
- Anzahl der Reisenden

### Zusätzliche Daten

- Unterkunftsart
- Besondere Anforderungen
- Ernährungsvorlieben (für CO2-Berechnung)

## Zugriff auf das Formular

Teilnehmer greifen auf das Formular über eine öffentliche URL zu:

```
/project/[project-id]/participate
```

Dieser Link kann:

- Per E-Mail gesendet werden
- In Messaging-Apps geteilt werden
- Auf Websites gepostet werden
- In QR-Codes eingeschlossen werden

## Für Projektorganisatoren

### Den Link erhalten

1. Gehen Sie zu Ihrer Projektdetails-Seite
2. Finden Sie den Abschnitt "Teilnahmelink"
3. Kopieren Sie den Link oder laden Sie den QR-Code herunter

### Best Practices für Teilen

- Senden Sie den Link weit im Voraus der Aktivität
- Schließen Sie Anweisungen ein, welche Informationen Teilnehmer benötigen
- Setzen Sie eine Frist für Einreichungen
- Senden Sie Erinnerungen an diejenigen, die nicht eingereicht haben

## Für Teilnehmer

### Vor dem Ausfüllen des Formulars

Halten Sie die folgenden Informationen bereit:

- Ihren Reiseplan
- Abreise- und Ankunftsort
- Transportmittel
- Anzahl der gemeinsam reisenden Personen

### Datenschutz

- Ihre Daten sind nur für die Projektorganisatoren sichtbar
- CO2-Berechnungen werden für Berichterstattung aggregiert
- Persönliche Informationen werden gemäß DSGVO behandelt

## Datenvalidierung

Das Formular umfasst Validierung, um sicherzustellen:

- Alle erforderlichen Felder sind ausgefüllt
- E-Mail-Adressen sind gültig
- Reiseentfernungen sind angemessen
- Daten liegen innerhalb des Projektzeitraums

## Fehlerbehebung

### Formular wird nicht abgesendet

- Überprüfen Sie, dass alle erforderlichen Felder ausgefüllt sind
- Stellen Sie sicher, dass Ihre E-Mail-Adresse gültig ist
- Versuchen Sie, die Seite zu aktualisieren

### Falsches Projekt

- Verifizieren Sie, dass Sie den richtigen Teilnahmelink verwenden
- Kontaktieren Sie den Projektorganisator, falls unsicher

### Kann nicht auf das Formular zugreifen

- Das Projekt könnte für neue Einreichungen geschlossen sein
- Kontaktieren Sie den Organisator für Hilfe
