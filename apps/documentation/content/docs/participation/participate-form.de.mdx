# Teilnahmeformular

Das Teilnahmeformular ist der primäre Weg für Projektteilnehmer, ihre Reiseinformationen und CO2-Fußabdruck-Daten einzureichen.

## Zugriff auf das Formular

### Öffentlicher Link

Teilnehmer greifen auf das Formular über eine eindeutige URL zu:

```
https://greendex.world/project/[project-id]/participate
```

### Wie man den Link erhält

Organisatoren teilen den Link über:

- **E-Mail** - Direkt an Teilnehmer senden
- **Messaging-Apps** - WhatsApp, Telegram, etc.
- **Projektwebsite** - Auf der Event-Seite posten
- **QR-Code** - Scannen zum Zugriff
- **Soziale Medien** - In Gruppen teilen

### QR-Code-Zugriff

Für einfachen mobilen Zugriff:

1. Organisatoren generieren QR-Code aus Projektdetails
2. An Veranstaltungsorten anzeigen oder in Materialien einschließen
3. Teilnehmer scannen mit der Handykamera
4. Öffnet automatisch das Teilnahmeformular

## Formularübersicht

### Formularstruktur

Das Teilnahmeformular ist in Abschnitte organisiert:

1. **Willkommen** - Projektinformationen und Anweisungen
2. **Persönliche Informationen** - Name, E-Mail, Land
3. **Reiseinformationen** - Transportdetails
4. **Zusätzliche Informationen** - Ernährung, Unterkunft
5. **Überprüfung** - Zusammenfassung vor Einreichung
6. **Bestätigung** - Erfolgsnachricht

### Fortschrittsindikator

Eine Fortschrittsleiste zeigt:

- Aktueller Schritt
- Abgeschlossene Schritte
- Verbleibende Schritte
- Geschätzte Zeit zum Abschluss

## Formular ausfüllen

### Schritt 1: Persönliche Informationen

#### Name

- Geben Sie Ihren vollständigen Namen ein
- Wie Sie in Projektunterlagen erscheinen möchten
- Kann später bei Bedarf aktualisiert werden

#### E-Mail-Adresse

- Geben Sie eine gültige E-Mail an
- Wird für Bestätigung und Updates verwendet
- Muss für Sie zugänglich sein

#### Herkunftsland

- Wählen Sie Ihr Heimatland
- Wird für CO2-Berechnungen verwendet
- Beeinflusst Entfernungsschätzungen

**Validierung:**

- Name kann nicht leer sein
- E-Mail muss gültiges Format haben
- Land muss ausgewählt werden

### Schritt 2: Reiseinformationen

#### Transportmittel

Wählen Sie, wie Sie gereist sind:

| Transport    | Description            | Emissions Factor |
| ------------ | ---------------------- | ---------------- |
| ✈️ **Plane** | Air travel             | High             |
| 🚆 **Train** | Rail travel            | Low              |
| 🚌 **Bus**   | Coach or bus           | Medium           |
| 🚗 **Car**   | Private vehicle        | Varies           |
| 🚲 **Other** | Bicycle, walking, etc. | None/Very low    |

#### Routendetails

**Von (Abreise)**

- Stadt und Land, aus dem Sie gereist sind
- Seien Sie so spezifisch wie möglich
- Wird für Entfernungsberechnung verwendet

**Nach (Ziel)**

- Projektveranstaltungsort
- Normalerweise vom Organisator vorausgefüllt
- Verifizieren Sie, dass es korrekt ist

#### Entfernung

Optionen zur Angabe der Entfernung:

**Automatische Berechnung**

- System schätzt basierend auf Standorten
- Verwendet Standardrouting
- Gut für die meisten Fälle

**Manuelle Eingabe**

- Geben Sie die genaue Entfernung ein, falls bekannt
- Nützlich für komplexe Routen
- Automatische Berechnung überschreiben

**Einheiten:**

- Kilometer (km) - Standard
- Meilen - Falls bevorzugt

#### Reisende

Anzahl der reisenden Personen:

- **1** - Nur Sie
- **2+** - Gemeinsamer Transport
- Beeinflusst die CO2-Berechnung pro Person

Für gemeinsamen Transport:

- Gesamtemissionen geteilt durch Reisende
- Mehr Reisende = niedrigerer pro-Person-Auswirkung

### Schritt 3: Zusätzliche Informationen

#### Ernährungsvorlieben

Wählen Sie Ihre typische Ernährung:

- **Omnivore** - Alles essen
- **Vegetarian** - Kein Fleisch
- **Vegan** - Keine tierischen Produkte
- **Andere** - Bei Bedarf angeben

**Zweck:** Ernährung beeinflusst CO2-Fußabdruck-Berechnungen für das Projekt.

#### Unterkunft

Wo Sie bleiben werden:

- **Hotel** - Kommerzielle Unterkunft
- **Hostel** - Gemeinsame Unterkunft
- **Privat** - Bei Einheimischen/Freunden
- **Andere** - Angegeben

#### Besondere Anforderungen

Optionales Feld für:

- Barrierefreiheitsbedürfnisse
- Ernährungseinschränkungen
- Medizinische Überlegungen
- Andere relevante Informationen

### Schritt 4: Überprüfung

Vor der Einreichung:

- Überprüfen Sie alle eingegebenen Informationen
- Auf Fehler prüfen
- Reise details verifizieren
- Bestätigen Sie, dass E-Mail korrekt ist

**Was zu prüfen:**

- Namensschreibweise
- E-Mail-Adresse
- Reiseroute
- Transportmittel
- Entfernung scheint angemessen

### Schritt 5: Einreichen

Klicken Sie auf **"Einreichen"**, um abzuschließen:

- Daten werden im Projekt gespeichert
- Bestätigungsnachricht erscheint
- E-Mail-Bestätigung gesendet
- Referenznummer bereitgestellt

## Nach der Einreichung

### Bestätigung

Sie sehen:

- Erfolgsnachricht
- Zusammenfassung der eingereichten Daten
- Referenznummer (speichern Sie diese!)
- Geschätzter CO2-Fußabdruck

### E-Mail-Bestätigung

Überprüfen Sie Ihren Posteingang auf:

- Bestätigung der Einreichung
- Zusammenfassung Ihrer Daten
- Referenznummer
- Kontaktinformationen für Fragen

### Was passiert als Nächstes

Ihre Daten werden:

- Zum Projekt hinzugefügt
- In CO2-Berechnungen eingeschlossen
- Für Projektorganisatoren sichtbar
- Für Berichterstattung verwendet

## Ihre Einreichung bearbeiten

### Kann ich bearbeiten?

Abhängig von Projekteinstellungen:

- **Bearbeitbar** - Kann bis zur Frist aktualisiert werden
- **Gesperrt** - Kann nach Einreichung nicht geändert werden
- **Organisator kontaktieren** - Änderungen anfordern

### Wie bearbeiten

Wenn Bearbeitung aktiviert ist:

1. Verwenden Sie den Link aus Ihrer Bestätigungs-E-Mail
2. Oder kontaktieren Sie Organisator für Bearbeitungslink
3. Änderungen vornehmen
4. Erneut einreichen

## Fehlerbehebung

### Formular lädt nicht

Wenn die Seite nicht erscheint:

- Internetverbindung prüfen
- Versuchen Sie einen anderen Browser
- Browser-Cache leeren
- Organisator für alternativen Link kontaktieren

### Kann nicht einreichen

Wenn die Einreich-Schaltfläche nicht funktioniert:

- Überprüfen Sie, dass alle erforderlichen Felder ausgefüllt sind
- Nach Validierungsfehlermeldungen suchen
- Stellen Sie sicher, dass E-Mail-Format korrekt ist
- Versuchen Sie, die Seite zu aktualisieren

### Entfernung scheint falsch

Wenn die berechnete Entfernung falsch ist:

- Verwenden Sie die Option für manuelle Eingabe
- Bekannte Entfernung eingeben
- Notiz für Organisator hinzufügen
- Organisator kontaktieren, falls signifikanter Fehler

### Falsches Projekt

Wenn Sie auf falsches Projekt zugegriffen haben:

- Nicht einreichen
- Organisator für korrekten Link kontaktieren
- Verifizieren Sie, dass Projektname zu Ihrer Aktivität passt

### E-Mail nicht erhalten

Wenn Bestätigungs-E-Mail nicht ankommt:

- Spam/Junk-Ordner prüfen
- Verifizieren Sie, dass E-Mail korrekt eingegeben wurde
- Ein paar Minuten warten
- Organisator kontaktieren, um Einreichung zu bestätigen

## Best Practices

### Für Teilnehmer

#### Vor dem Start

- **Informationen bereit haben** - Ihre Reisedetails kennen
- **Zeit lassen** - Nicht hetzen
- **Genave Daten verwenden** - Bessere Daten = bessere Berechnungen

#### Während des Ausfüllens

- **Seien Sie präzise** - Genave Standorte helfen bei Berechnungen
- **Rückreise einschließen** - Den Rückweg nicht vergessen
- **Zweimal prüfen** - Vor Einreichung überprüfen

#### Nach der Einreichung

- **Bestätigung speichern** - Referenznummer behalten
- **Auf E-Mail achten** - Spam prüfen, falls nicht erhalten
- **Bei Problemen kontaktieren** - Mit Fragen erreichen

### Für Organisatoren

#### Formular teilen

- **Früh senden** - Teilnehmern Zeit geben
- **Mehrere Erinnerungen** - Nicht-Einreichern nachfassen
- **Klare Anweisungen** - Erklären, was benötigt wird
- **Hilfe anbieten** - Unterstützung anbieten

#### Teilnehmer unterstützen

- **Fragen beantworten** - Reagieren
- **Fehler beheben** - Bei Korrekturen helfen
- **Fristen verlängern** - Bei Bedarf
- **Teilnehmer danken** - Einreichungen anerkennen

## Datenschutz und Daten

### Was wir sammeln

- Persönliche Informationen (Name, E-Mail, Land)
- Reisedetails (Transport, Route, Entfernung)
- Vorlieben (Ernährung, Unterkunft)

### Wie wir es verwenden

- CO2-Fußabdruck berechnen
- Projektberichte generieren
- Mit Updates kontaktieren
- Zukünftige Projekte verbessern

### Ihre Rechte

Gemäß DSGVO:

- **Zugriff** - Ihre Daten anzeigen
- **Korrektur** - Fehler beheben
- **Löschung** - Entfernung anfordern
- **Portabilität** - Ihre Daten exportieren

Um Rechte auszuüben, kontaktieren Sie den Projektorganisator.
