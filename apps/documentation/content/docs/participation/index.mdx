# Public Participation

The public participation feature allows project participants to submit their travel information and carbon footprint data through a simple, accessible form.

## How It Works

1. Project organizers [create a project](../docs/projects/create)
2. A unique [participation link](../docs/projects/details#share-project) is generated
3. Participants visit the [public link](../docs/participation/participate-form#public-link) and fill out the form
4. Data is automatically associated with the project
5. [Organizers and Team members](../docs/organization#member-roles) can view submissions in real-time

## Participation Form

The participation form collects:

### Personal Information

- Name
- Email address
- Country of origin

### Travel Information

- Mode of transport (plane, train, bus, car)
- Departure location
- Arrival location
- Distance traveled
- Number of travelers

### Additional Data

- Accommodation type
- Special requirements
- Dietary preferences (for carbon calculation)

## Accessing the Form

Participants access the form through a public URL:

```
/project/[project-id]/participate
```

This link can be:

- Sent via email
- Shared in messaging apps
- Posted on websites
- Included in QR codes

## For Project Organizers

### Getting the Link

1. Go to your project details page
2. Find the "Participation Link" section
3. Copy the link or download the QR code

### Sharing Best Practices

- Send the link well in advance of the activity
- Include instructions on what information participants need
- Set a deadline for submissions
- Send reminders to those who haven't submitted

## For Participants

### Before Filling the Form

Have the following information ready:

- Your travel itinerary
- Departure and arrival locations
- Mode of transport
- Number of people traveling together

### Privacy

- Your data is only visible to the project organizers
- Carbon calculations are aggregated for reporting
- Personal information is handled according to GDPR

## Data Validation

The form includes validation to ensure:

- All required fields are filled
- Email addresses are valid
- Travel distances are reasonable
- Dates are within the project period

## Troubleshooting

### Form Won't Submit

- Check that all required fields are filled
- Ensure your email address is valid
- Try refreshing the page

### Wrong Project

- Verify you're using the correct participation link
- Contact the project organizer if unsure

### Can't Access the Form

- The project might be closed to new submissions
- Contact the organizer for assistance
