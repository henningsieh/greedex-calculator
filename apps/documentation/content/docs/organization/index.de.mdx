# Organisation

Organisationen sind die oberste Ebene in Greendex. Jede Organisation repräsentiert eine juristische Person (Unternehmen, NGO, Institution), die Erasmus+-Projekte durchführt.

## Organisationsstruktur

Eine Organisation enthält:

- **Teammitglieder** - Personen, die die Organisation verwalten
- **Projekte** - Erasmus+-Aktivitäten, die verfolgt werden
- **Teilnehmer** - Personen, die an Projekten teilnehmen
- **Einstellungen** - Organisationskonfiguration

## Mitgliederrollen

Greendex verwendet ein rollenbasierendes Zugriffssystem:

### Eigentümer

- Vollständige Kontrolle über die Organisation
- Kann Mitglieder mit jeder Rolle einladen
- Kann die Organisation löschen
- Kann alle Projekte und Einstellungen verwalten

### Mitarbeiter

- Kann Projekte erstellen und verwalten
- Kann Teilnehmer einladen
- Kann Team- und Teilnehmerlisten anzeigen
- Kann die Organisation nicht löschen

### Teilnehmer

- Eingeschränkter Zugriff auf Projekte, an denen sie teilnehmen
- Kann keine anderen Mitglieder einladen
- Kann ihre CO2-Fußabdruck-Daten einreichen
