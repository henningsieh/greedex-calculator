# Organisationseinstellungen

Organisationseinstellungen ermöglichen es Ihnen, die Details, Präferenzen und Konfigurationsoptionen Ihrer Organisation zu verwalten.

## Zugriff auf Einstellungen

Um auf Ihre Organisationseinstellungen zuzugreifen:

1. Navigieren Sie zum Abschnitt **Organisation** in der Seitenleiste
2. Klicken Sie auf **Einstellungen**
3. Sie sehen das Einstellungsformular mit Ihren aktuellen Informationen

## Einstellungsübersicht

### Organisationsdetails

#### Name

- Der offizielle Name Ihrer Organisation
- Für alle Teammitglieder und Teilnehmer sichtbar
- Kann jederzeit geändert werden

#### Slug

- URL-freundlicher Bezeichner für Ihre Organisation
- Wird in einigen URLs und Referenzen verwendet
- Wird automatisch aus dem Namen generiert, kann aber angepasst werden

### Kontaktinformationen

#### E-Mail

- Primäre Kontakt-E-Mail für die Organisation
- Wird für wichtige Benachrichtigungen verwendet
- Sollte regelmäßig überwacht werden

#### Telefon (Optional)

- Kontakttelefonnummer
- Nützlich für dringende Kommunikationen

### Adressinformationen

#### Standort

- Physische Adresse Ihrer Organisation
- Wird für CO2-Fußabdruck-Berechnungen verwendet
- Wichtig für den Projektstandort-Kontext

#### Land

- Das Land, in dem Ihre Organisation ansässig ist
- Beeinflusst Zeitzone und regionale Einstellungen
- Wird in Berichterstattung und Compliance verwendet

## Einstellungen verwalten

### Organisationsdetails bearbeiten

1. Navigieren Sie zu **Einstellungen**
2. Ändern Sie die Felder, die Sie ändern möchten
3. Klicken Sie auf **"Änderungen speichern"**
4. Änderungen werden sofort wirksam

### Validierung

Das Einstellungsformular validiert:

- Erforderliche Felder sind ausgefüllt
- E-Mail-Format ist korrekt
- Telefonnummern sind gültig
- Namen sind nicht leer

## Erweiterte Einstellungen

### Zeitzone

Stellen Sie die Standardzeitzone Ihrer Organisation ein:

- Beeinflusst Projekttermine und -zeiten
- Wird für Berichtsperioden verwendet
- Kann bei Bedarf pro Projekt überschrieben werden

### Sprache

Standardsprache für Ihre Organisation:

- Beeinflusst Systembenachrichtigungen
- Wird für Teilnehmerkommunikation verwendet
- Unterstützt derzeit: Englisch, Deutsch und mehr

### Branding (Zukunft)

Geplante Funktionen umfassen:

- Benutzerdefiniertes Logo-Upload
- Farbschema-Anpassung
- Markierte Teilnehmerformulare

## Berechtigungen

### Wer kann auf Einstellungen zugreifen

| Rolle                      | Einstellungen anzeigen | Einstellungen bearbeiten |
| -------------------------- | ---------------------- | ------------------------ |
| Organisationsadministrator | ✅                     | ✅                       |
| Projektkoordinator         | ✅                     | ❌                       |
| Teilnehmer                 | ❌                     | ❌                       |

Nur **Organisationsadministratoren** können Organisationseinstellungen ändern. Projektkoordinatoren können Einstellungen anzeigen, aber keine Änderungen vornehmen.

## Gefahrenzone

### Organisation löschen

**Warnung**: Diese Aktion ist irreversibel.

Um Ihre Organisation zu löschen:

1. Gehen Sie zu Einstellungen
2. Scrollen Sie zum Abschnitt "Gefahrenzone"
3. Klicken Sie auf **"Organisation löschen"**
4. Bestätigen Sie die Löschung

**Was gelöscht wird:**

- Alle Organisationsdaten
- Alle Projekte und deren Daten
- Alle Teilnehmerinformationen
- Teammitglieder-Assoziationen

**Was vor dem Löschen zu tun ist:**

- Exportieren Sie wichtige Daten
- Benachrichtigen Sie Teammitglieder
- Schließen Sie aktive Projekte ab oder übertragen Sie sie

## Fehlerbehebung

### Änderungen werden nicht gespeichert

Wenn Ihre Einstellungsänderungen nicht bestehen bleiben:

- Überprüfen Sie auf Validierungsfehler
- Stellen Sie sicher, dass Sie auf "Änderungen speichern" geklickt haben
- Verifizieren Sie, dass Sie Berechtigungen als Organisationsadministrator haben
- Versuchen Sie, die Seite zu aktualisieren

### Ungültiger E-Mail-Fehler

- Stellen Sie sicher, dass das E-Mail-Format korrekt ist (z.B. name@domain.com)
- Überprüfen Sie auf Tippfehler oder zusätzliche Leerzeichen
- Verwenden Sie eine gültige, zugängliche E-Mail-Adresse

### Slug bereits vergeben

Wenn Ihr bevorzugter Slug nicht verfügbar ist:

- Fügen Sie einen Standort- oder Abteilungsbezeichner hinzu
- Verwenden Sie eine Abkürzung
- Kontaktieren Sie den Support, wenn Sie glauben, dass es einen Konflikt gibt

## Best Practices

### Informationen aktuell halten

- **Jährlich aktualisieren** - Überprüfen Sie Einstellungen mindestens einmal im Jahr
- **Nach Umzügen** - Aktualisieren Sie die Adresse, wenn Ihre Organisation umzieht
- **Kontaktänderungen** - Halten Sie E-Mail und Telefon aktuell
- **Rebranding** - Aktualisieren Sie Name und Details, wenn Ihre Organisation rebranded

### Sicherheitsüberlegungen

- **Verwenden Sie Organisations-E-Mail** - Nicht eine persönliche E-Mail-Adresse
- **Überwachen Sie Zugriff** - Nur Organisationsadministratoren sollten Zugriff auf Einstellungen haben
- **Regelmäßige Audits** - Überprüfen Sie, wer Berechtigungen als Organisationsadministrator hat
