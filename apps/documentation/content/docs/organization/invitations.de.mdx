# Teameinladungen

Das Einladungssystem ermöglicht es Ihnen, neue Mitglieder zu Ihrer Organisation hinzuzufügen. Dies umfasst sowohl das Senden von Einladungen als auch deren Annahme.

## Einladungen senden

### Wer kann einladen

- **Eigentümer** können Mitglieder mit jeder Rolle einladen (Eigentümer, Mitarbeiter, Teilnehmer)
- **Mitarbeiter** können nur Teilnehmer einladen

### Wie man eine Einladung sendet

1. Gehen Sie zur **Team**-Seite (`/org/team`)
2. Klicken Sie auf die Schaltfläche **"Mitglied einladen"**
3. Füllen Sie das Einladungsformular aus:
   - **E-Mail** - Die E-Mail-Adresse des Eingeladenen
   - **Name** - Der vollständige Name des Eingeladenen
   - **Rolle** - Wählen Sie die entsprechende Rolle (Eigentümer, Mitarbeiter oder Teilnehmer)
4. Klicken Sie auf **"Einladung senden"**

### Was passiert als Nächstes

- Der Eingeladene erhält eine E-Mail mit einem Einladungslink
- Die Einladung erscheint in der Teamliste als "Ausstehend"
- Der Eingeladene muss die Einladung annehmen, um beizutreten

## Einladungen annehmen

### Für neue Benutzer

Wenn der Eingeladene kein Greendex-Konto hat:

1. Klicken Sie auf den Einladungslink in der E-Mail
2. Sie werden zur Registrierungsseite weitergeleitet
3. Erstellen Sie ein Konto
4. Nach der Verifizierung treten Sie automatisch der Organisation bei

### Für bestehende Benutzer

Wenn der Eingeladene bereits ein Greendex-Konto hat:

1. Klicken Sie auf den Einladungslink in der E-Mail
2. Melden Sie sich an, falls aufgefordert
3. Klicken Sie auf **"Einladung annehmen"** auf der Annahmenseite
4. Sie werden der Organisation hinzugefügt und zum Dashboard weitergeleitet

## Einladungen verwalten

### Ausstehende Einladungen anzeigen

Ausstehende Einladungen werden auf der Team-Seite mit dem Status "Ausstehend" angezeigt.

### Einladungen stornieren

Eigentümer können ausstehende Einladungen von der Team-Seite stornieren.

## Rollenberechtigungen

| Rolle       | Kann Eigentümer einladen | Kann Mitarbeiter einladen | Kann Teilnehmer einladen |
| ----------- | ------------------------ | ------------------------- | ------------------------ |
| Eigentümer  | ✅                       | ✅                        | ✅                       |
| Mitarbeiter | ❌                       | ❌                        | ✅                       |
| Teilnehmer  | ❌                       | ❌                        | ❌                       |

## Fehlerbehebung

### Einladung nicht erhalten

- Überprüfen Sie Spam/Junk-Ordner
- Verifizieren Sie, dass die E-Mail-Adresse korrekt eingegeben wurde
- Versuchen Sie, die Einladung erneut zu senden

### Einladungslink abgelaufen

Kontaktieren Sie einen Organisationseigentümer, um eine neue Einladung zu senden.
