# Teamverwaltung

Die Team-Seite ermöglicht es Ihnen, die Teammitglieder Ihrer Organisation anzuzeigen und zu verwalten - Eigentümer und Mitarbeiter, die bei der Verwaltung der Organisation und ihrer Projekte helfen.

## Teamrollen verstehen

### Eigentümer

**Vollständige administrative Kontrolle:**

- Kann Mitglieder mit jeder Rolle einladen
- Kann die Organisation löschen
- Kann alle Projekte und Einstellungen verwalten
- Kann jedes Teammitglied entfernen
- Kann die Eigentümerschaft übertragen

**Am besten für:** Organisationsadministratoren, Projektkoordinatoren

### Mitarbeiter

**Projektmanagement-Zugriff:**

- Kann Projekte erstellen und verwalten
- Kann Teilnehmer einladen
- Kann Team- und Teilnehmerlisten anzeigen
- Kann die Organisation nicht löschen
- Kann keine Eigentümer oder Mitarbeiter einladen

**Am besten für:** Projektmanager, Koordinatoren, Support-Mitarbeiter

### Teilnehmer

**Eingeschränkter Projektzugriff:**

- Kann an zugewiesenen Projekten teilnehmen
- Kann CO2-Fußabdruck-Daten einreichen
- Kann keine anderen Mitglieder einladen
- Kann nicht auf Teamverwaltung zugreifen

**Am besten für:** Projektteilnehmer, Freiwillige

## Ihr Team anzeigen

### Teamliste

Die Team-Seite zeigt:

- **Name** - Vollständiger Name des Teammitglieds
- **E-Mail** - Kontakt-E-Mail-Adresse
- **Rolle** - Aktuelle Rolle in der Organisation
- **Status** - Aktiv oder ausstehende Einladung
- **Beigetreten** - Wann sie Mitglied wurden

### Filtern und Sortieren

Verwenden Sie die Tabellensteuerungen, um:

- **Suchen** - Mitglieder nach Name oder E-Mail finden
- **Nach Rolle filtern** - Nur Eigentümer, Mitarbeiter oder alle anzeigen
- **Sortieren** - Nach Name, Rolle oder Beitrittsdatum ordnen
- **Paginierung** - Durch große Teams navigieren

## Teammitglieder verwalten

### Neue Mitglieder einladen

Siehe die Seite [Einladungen](/docs/organization/invitations) für detaillierte Anweisungen zum Einladen von Teammitgliedern.

Schnellübersicht:

1. Klicken Sie auf **"Mitglied einladen"**
2. Geben Sie E-Mail und Name ein
3. Rolle auswählen
4. Einladung senden

### Ausstehende Einladungen anzeigen

Ausstehende Einladungen erscheinen in der Teamliste mit:

- "Ausstehend"-Status-Badge
- Einladungsdatum
- Rolle, als die sie eingeladen wurden

### Einladungen stornieren

Um eine ausstehende Einladung zu stornieren:

1. Finden Sie das ausstehende Mitglied in der Liste
2. Klicken Sie auf die Schaltfläche **"Stornieren"**
3. Bestätigen Sie die Stornierung

Der Eingeladene kann die Einladung nicht mehr annehmen.

## Rollenverwaltung

### Rollen ändern

Eigentümer können Mitgliederrollen ändern:

1. Finden Sie das Teammitglied in der Liste
2. Klicken Sie auf ihre aktuelle Rolle
3. Wählen Sie die neue Rolle aus dem Dropdown
4. Bestätigen Sie die Änderung

### Rollenänderungs-Berechtigungen

| Aktion                  | Eigentümer | Mitarbeiter | Teilnehmer |
| ----------------------- | ---------- | ----------- | ---------- |
| Zu Eigentümer befördern | ✅         | ❌          | ❌         |
| Eigentümer degradieren  | ✅         | ❌          | ❌         |
| Zu Mitarbeiter ändern   | ✅         | ❌          | ❌         |
| Zu Teilnehmer ändern    | ✅         | ✅\*        | ❌         |

\*Mitarbeiter können nur Teilnehmer zu anderen Rollen ändern

### Eigentümerschaft übertragen

Um die Organisationseigentümerschaft zu übertragen:

1. Gehen Sie zur Team-Seite
2. Finden Sie das Mitglied, das befördert werden soll
3. Ändern Sie ihre Rolle zu **Eigentümer**
4. (Optional) Sich selbst zu Mitarbeiter degradieren

**Hinweis:** Eine Organisation muss immer mindestens einen Eigentümer haben.

## Teammitglieder entfernen

### Ein Mitglied entfernen

Eigentümer können Teammitglieder entfernen:

1. Finden Sie das Mitglied in der Teamliste
2. Klicken Sie auf die Schaltfläche **"Entfernen"**
3. Bestätigen Sie die Entfernung

**Was passiert beim Entfernen:**

- Mitglied verliert Zugriff auf die Organisation
- Ihre Teilnehmerdaten bleiben in Projekten
- Sie können später erneut eingeladen werden
- Ihr Konto bleibt für andere Organisationen aktiv

### Kann sich nicht selbst entfernen

Sie können sich nicht selbst aus der Organisation entfernen:

- Bitten Sie einen anderen Eigentümer, Sie zu entfernen
- Oder löschen Sie Ihr Konto vollständig

## Teamgrößen-Limits

### Aktuelle Limits

- **Kein hartes Limit** für Teamgröße
- Praktische Limits basierend auf Ihrem Plan
- Kontaktieren Sie den Support für große Organisationsanforderungen

### Best Practices

- **Regelmäßige Audits** - Überprüfen Sie die Teammitgliedschaft vierteljährlich
- **Prinzip der geringsten Berechtigung** - Geben Sie minimale notwendige Zugriffe
- **Inaktive entfernen** - Bereinigen Sie Mitglieder, die nicht mehr teilnehmen
- **Rollen dokumentieren** - Behalten Sie im Auge, wer was tut

## Fehlerbehebung

### Mitglied wird nicht angezeigt

Wenn ein Teammitglied nicht erscheint:

- Überprüfen Sie, ob sie stattdessen in der Teilnehmerliste sind
- Verifizieren Sie, dass die Einladung angenommen wurde
- Stellen Sie sicher, dass Sie die richtige Organisation anzeigen
- Überprüfen Sie, ob Filter sie nicht verstecken

### Kann Rolle nicht ändern

Wenn Sie die Rolle eines Mitglieds nicht ändern können:

- Verifizieren Sie, dass Sie Eigentümer-Berechtigungen haben
- Überprüfen Sie, ob sie der einzige Eigentümer sind (muss mindestens einen haben)
- Stellen Sie sicher, dass das Mitglied seine Einladung angenommen hat

### Einladungsprobleme

Für Einladungsprobleme siehe [Einladungs-Fehlerbehebung](/docs/organization/invitations#troubleshooting).

## Sicherheits-Best Practices

### Zugriffskontrolle

- **Eigentümer begrenzen** - Nur vertrauenswürdige Administratoren sollten Eigentümer sein
- **Regelmäßige Überprüfungen** - Rollen vierteljährlich auditieren
- **Offboarding** - Zugriff entfernen, wenn Teammitglieder gehen
- **Einladungen überwachen** - Ausstehende Einladungen verfolgen

### Sensible Operationen

Nur Eigentümer können:

- Die Organisation löschen
- Auf Rechnungsinformationen zugreifen
- Kritische Einstellungen ändern
- Andere Eigentümer entfernen
