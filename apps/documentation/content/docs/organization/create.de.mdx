# Organisation erstellen

Die Erstellung einer Organisation ist der erste Schritt nach der E-Mail-Verifizierung. Organisationen repräsentieren Ihre juristische Person (Unternehmen, NGO, Institution), die Erasmus+-Projekte durchführt.

## Wann eine Organisation erstellen

Sie werden aufgefordert, eine Organisation zu erstellen:

- Unmittelbar nach der E-Mail-Verifizierung
- Wenn Sie sich ohne bestehende Organisationen anmelden
- Wenn Sie alle Organisationen verlassen und eine neue benötigen

## Prozess der Organisationerstellung

### Schritt 1: Zugriff auf das Erstellungsformular

Nach der Anmeldung, wenn Sie keine Organisationen haben:

- Sie werden automatisch zur Seite für die Organisationerstellung weitergeleitet
- Die Seite zeigt ein einfaches Formular zum Einstieg

### Schritt 2: Organisationsdetails eingeben

Füllen Sie die erforderlichen Informationen aus:

#### Organisationsname (Erforderlich)

- Geben Sie den offiziellen Namen Ihrer Organisation ein
- Dieser Name ist für Teammitglieder und Teilnehmer sichtbar
- Sie können dies später in den Einstellungen ändern

#### Organisations-Slug (Automatisch generiert)

- Eine URL-freundliche Version Ihres Namens
- Wird in einigen URLs und Referenzen verwendet
- Wird normalerweise automatisch aus dem Namen generiert

### Schritt 3: Formular absenden

Klicken Sie auf **"Organisation erstellen"**, um die Einrichtung abzuschließen.

## Was passiert als Nächstes

Nach der Erstellung Ihrer Organisation:

1. **Organisation erstellt** - Ihre Organisation ist nun aktiv
2. **Sie sind der Eigentümer** - Sie haben die volle Kontrolle über die Organisation
3. **Weiterleitung zum Dashboard** - Sie werden zu Ihrem Organisations-Dashboard gebracht
4. **Bereit, Team einzuladen** - Sie können nun Mitglieder hinzufügen

## Organisationsgrenzen

### Eine Organisation pro Benutzer

Derzeit ist jedes Benutzerkonto über Mitgliedschaft mit einer Organisation gleichzeitig verbunden. Sie können:

- Mitglied mehrerer Organisationen sein (über Einladungen)
- Zwischen Organisationen wechseln, denen Sie angehören
- Bei Bedarf zusätzliche Organisationen erstellen

### Eigentümerschaft

Als Ersteller:

- Sie werden automatisch zum **Eigentümer**
- Sie können andere Eigentümer, Mitarbeiter oder Teilnehmer einladen
- Sie können die Eigentümerschaft an ein anderes Mitglied übertragen
- Sie können die Organisation bei Bedarf löschen

## Fehlerbehebung

### "Organisation existiert bereits"

Wenn Sie diesen Fehler sehen:

- Der Organisationsname ist möglicherweise bereits vergeben
- Versuchen Sie einen anderen, spezifischeren Namen
- Fügen Sie Standort oder Abteilung hinzu, um ihn einzigartig zu machen

### Formular wird nicht abgesendet

- Stellen Sie sicher, dass der Organisationsname ausgefüllt ist
- Überprüfen Sie auf Validierungsfehler
- Versuchen Sie, die Seite zu aktualisieren und es erneut zu versuchen

### Zurück zur Erstellungsseite weitergeleitet

Wenn Sie nach der Erstellung zurückgeleitet werden:

- Die Organisation wurde möglicherweise nicht erfolgreich erstellt
- Überprüfen Sie Ihre Netzwerkverbindung
- Versuchen Sie, die Organisation erneut zu erstellen

## Best Practices

### Auswahl eines Organisationsnamens

- **Verwenden Sie den offiziellen Namen** - Entsprechen Sie Ihrem juristischen Namen
- **Seien Sie spezifisch** - Fügen Sie den Standort hinzu, wenn Sie mehrere Kapitel haben
- **Halten Sie es professionell** - Dieser Name ist für Teilnehmer sichtbar
- **Vermeiden Sie Abkürzungen** - Es sei denn, sie sind allgemein bekannt

### Einrichtung Ihrer Organisation

Nach der Erstellung erwägen Sie:

1. [Teammitglieder einladen](/docs/organization/invitations), um bei der Verwaltung zu helfen
2. [Einstellungen konfigurieren](/docs/organization/settings) wie Zeitzone
3. [Ihr erstes Projekt erstellen](/docs/projects/create)
4. Branding und Anpassungen einrichten

## Multi-Organisations-Benutzer

Wenn Sie mehreren Organisationen angehören:

### Organisationen wechseln

1. Verwenden Sie den Organisationswechsler in der Seitenleiste
2. Wählen Sie die Organisation aus, mit der Sie arbeiten möchten
3. Ihr Dashboard und Projekte werden automatisch aktualisiert

### Organisationskontext

- Alle Aktionen werden im Kontext der aktiven Organisation ausgeführt
- Projekte, Teilnehmer und Teammitglieder sind organisationsspezifisch
- Einstellungen gelten für die aktuell ausgewählte Organisation
