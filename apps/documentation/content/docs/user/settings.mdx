# User Settings

User Settings allows you to customize your Greendex experience, manage your account details, and configure personal preferences.

## Accessing User Settings

Navigate to your settings:

### Method 1: Profile Menu

1. Click your profile picture/avatar in the top navigation
2. Select **"Settings"** from the dropdown
3. The settings page opens

### Method 2: Sidebar Navigation

1. Look for **"User"** section in the sidebar
2. Click **"Settings"**
3. Manage your preferences

## Settings Sections

### Profile Settings

#### Display Name

- Your name as shown in Greendex
- Visible to team members and collaborators
- Can be changed at any time

**To update:**

1. Go to Profile section
2. Edit the **Display Name** field
3. Click **"Save"**

#### Email Address

- Primary contact and login email
- Must be unique across the platform
- Requires verification if changed

**To change email:**

1. Go to Profile section
2. Click **"Change Email"**
3. Enter new email address
4. Confirm with current password
5. Verify new email via link sent

**Important:** Changing email requires re-verification.

#### Profile Picture

- Avatar image for identification
- Displayed in team lists and comments
- Optional but recommended

**To update picture:**

1. Click current avatar
2. Upload new image
3. Crop if necessary
4. Save changes

**Supported formats:** JPG, PNG, GIF
**Maximum size:** 2MB

### Language and Region

#### Interface Language

Choose your preferred language:

- **English** (default)
- **German**
- More languages coming soon

**To change language:**

1. Go to **Language** section
2. Select from dropdown
3. Changes apply immediately

**Note:** This only affects the interface. Project data remains in its original language.

#### Timezone

Set your local timezone:

- Affects date/time displays
- Used for notifications
- Important for project deadlines

**To set timezone:**

1. Go to **Region** section
2. Select your timezone
3. Or use "Auto-detect" for automatic setting

### Appearance

#### Theme

Select visual theme:

**Options:**

- **Light** - Clean, bright interface
- **Dark** - Reduced eye strain in low light
- **System** - Matches your device setting

**To change theme:**

1. Go to **Appearance** section
2. Select preferred theme
3. Change applies immediately

#### Density

Control information density:

- **Compact** - More information, less spacing
- **Comfortable** - Balanced spacing
- **Spacious** - Maximum breathing room

### Notifications

#### Email Notifications

Configure email delivery:

**Types:**

- **Project updates** - Changes to your projects
- **Invitations** - Team and project invites
- **Reminders** - Upcoming deadlines
- **System** - Platform announcements

**Frequency options:**

- **Immediate** - Send right away
- **Daily digest** - Once per day summary
- **Weekly** - Weekly summary
- **Never** - No emails

#### In-App Notifications

Configure on-platform alerts:

- **Real-time** - Show immediately
- **Badge only** - Just update counters
- **Disabled** - No in-app notifications

### Security

#### Change Password

Update your account password:

1. Go to **Security** section
2. Click **"Change Password"**
3. Enter current password
4. Enter new password (min 6 characters)
5. Confirm new password
6. Click **"Update Password"**

**Password tips:**

- Use unique password (not used elsewhere)
- Mix uppercase, lowercase, numbers, symbols
- Avoid dictionary words
- Consider a passphrase

#### Two-Factor Authentication (2FA)

Add extra security layer:

**To enable:**

1. Go to **Security** section
2. Click **"Enable 2FA"**
3. Scan QR code with authenticator app
4. Enter verification code
5. Save backup codes securely

**Supported apps:**

- Google Authenticator
- Authy
- Microsoft Authenticator
- Any TOTP-compatible app

#### Active Sessions

View and manage logins:

**Information shown:**

- Device/browser
- Location (approximate)
- Last active time
- Current session indicator

**Actions:**

- **Revoke** - Sign out specific session
- **Revoke all** - Sign out everywhere except current

### Privacy

#### Data Visibility

Control what others see:

- **Profile visibility** - Who can see your profile
- **Activity status** - Show when you're active
- **Read receipts** - Show when you've seen messages

#### Data Export

Download your data:

1. Go to **Privacy** section
2. Click **"Export My Data"**
3. Select data types
4. Choose format (JSON, CSV)
5. Download file

**Includes:**

- Profile information
- Organization memberships
- Project participation
- Activity history

#### Delete Account

Permanently remove your account:

**Warning:** This cannot be undone.

1. Go to **Privacy** section
2. Scroll to **"Danger Zone"**
3. Click **"Delete Account"**
4. Read warnings carefully
5. Enter password to confirm
6. Click **"Permanently Delete"**

**Before deleting:**

- Transfer organization ownership if needed
- Export any data you want to keep
- Notify team members
- Consider leaving organizations instead

## Organization Context

### Current Organization

Settings are scoped to your current organization:

- Some settings are global (profile, password)
- Some are per-organization (notifications, role)
- Check organization indicator in header

### Switching Context

To change organization context:

1. Use organization switcher
2. Or go to Organizations list
3. Select different organization
4. Settings may change based on context

## Settings Sync

### Cross-Device

Settings sync across devices:

- Log in on any device
- Your preferences follow you
- Theme, language, notifications

### Exceptions

Some settings are device-specific:

- Active sessions (per device)
- Notification permissions (browser)
- Some appearance settings

## Troubleshooting

### Changes Not Saving

If settings don't persist:

- Check internet connection
- Verify you clicked "Save"
- Look for validation errors
- Try refreshing the page

### Can't Change Email

If email update fails:

- New email may already be in use
- Current password may be incorrect
- Verification email may be in spam
- Contact support if stuck

### Theme Not Applying

If appearance changes don't work:

- Clear browser cache
- Check for browser extensions interfering
- Try different browser
- Disable "System" theme and select manually

### Notifications Not Working

If you're not receiving notifications:

- Check notification permissions in browser
- Verify email address is correct
- Check spam/junk folders
- Ensure notifications are enabled in settings

## Best Practices

### Security

- **Enable 2FA** - Adds important security layer
- **Regular password updates** - Change every 3-6 months
- **Review sessions** - Check active logins monthly
- **Strong password** - Use password manager

### Personalization

- **Set correct timezone** - Ensures accurate deadlines
- **Choose comfortable theme** - Reduces eye strain
- **Configure notifications** - Balance awareness and noise
- **Complete profile** - Helps team identify you

### Maintenance

- **Review settings quarterly** - Ensure still appropriate
- **Update email if changed** - Maintain access
- **Export data periodically** - Keep backups
- **Revoke old sessions** - Clean up unused devices
