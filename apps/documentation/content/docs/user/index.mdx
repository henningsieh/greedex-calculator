# User Account

Your Greendex user account is your personal identity within the platform, allowing you to access organizations, projects, and manage your preferences.

## Account Overview

Your user account includes:

- **Personal information** - Name and email
- **Authentication** - Password and security settings
- **Organization memberships** - Organizations you belong to
- **Preferences** - Language, theme, and settings
- **Activity history** - Your actions within Greendex

## Account Creation

### During Sign Up

When you create an account:

1. Provide your email address
2. Create a secure password
3. Verify your email
4. Your account is activated

### Through Invitation

If invited to an organization:

1. Click invitation link
2. Create account (if new user)
3. Accept invitation
4. Join the organization

## Account Types

### Regular User

Standard account for:

- Organization members
- Project participants
- Team collaborators

### Organization Organization Administrator

Enhanced account with:

- Organization management rights
- Billing access (if applicable)
- Member management permissions

## Managing Your Account

### Accessing Account Settings

Navigate to your settings:

1. Click your profile/avatar in the navigation
2. Select **"Settings"** or **"Account"**
3. Manage your preferences

Or:

1. Go to **User** section in sidebar
2. Click **"Settings"**
3. Update your information

### Profile Information

#### Name

- Your display name
- Visible to team members
- Can be changed anytime

#### Email

- Primary contact address
- Used for login
- Requires verification if changed

#### Profile Picture

- Avatar image
- Helps identify you in the platform
- Optional but recommended

## Security

### Password Management

#### Changing Password

1. Go to Account Settings
2. Click **"Change Password"**
3. Enter current password
4. Enter new password
5. Confirm new password

**Password requirements:**

- Minimum 8 characters
- Recommended: mix of letters, numbers, symbols
- Should be unique (not used elsewhere)

#### Forgot Password

If you forget your password:

1. Go to login page
2. Click **"Forgot Password"**
3. Enter your email
4. Follow reset link in email
5. Create new password

See [Forgot Password](/docs/authentication/forgot-password) for details.

### Two-Factor Authentication (2FA)

If enabled for your organization:

1. Go to Security settings
2. Enable 2FA
3. Scan QR code with authenticator app
4. Enter verification code
5. Save backup codes

### Session Management

View and manage active sessions:

- **Current session** - Your current login
- **Other devices** - Logins from other locations
- **Revoke access** - Sign out other sessions

## Preferences

### Language Settings

Choose your preferred language:

1. Go to User Settings
2. Select **Language**
3. Choose from available options:
   - English
   - German
   - (More languages coming)

**Note:** This affects the interface language. Project data remains in its original language.

### Theme Preferences

Select visual theme:

- **Light** - Bright interface
- **Dark** - Dark mode for low light
- **System** - Follows device setting

### Notifications

Configure notification preferences:

- **Email notifications** - Project updates, invitations
- **In-app notifications** - Real-time alerts
- **Frequency** - Immediate, daily digest, or weekly

## Organization Memberships

### Viewing Your Organizations

See all organizations you belong to:

1. Go to User Settings
2. Click **"Organizations"** tab
3. View list with your role in each

### Switching Organizations

If member of multiple:

1. Use organization switcher in sidebar
2. Or go to Organizations list
3. Click to switch context

### Leaving an Organization

To leave an organization:

1. Go to Organizations list
2. Find the organization
3. Click **"Leave"**
4. Confirm your decision

**Note:** You cannot leave if you're the only Organization Administrator.

### Transferring Organization Administratorship

Before leaving as Organization Administrator:

1. Promote another member to Organization Administrator
2. Or delete the organization
3. Then you can leave

## Account Deletion

### Deleting Your Account

**Warning:** This is permanent and irreversible.

To delete your account:

1. Go to Account Settings
2. Scroll to **"Danger Zone"**
3. Click **"Delete Account"**
4. Confirm deletion
5. Enter password to verify

**What gets deleted:**

- Your user profile
- Personal settings
- Organization memberships
- Associated data

**What remains:**

- Submitted participant data (anonymized)
- Project records (without your identity)
- Organization continues operating

### Before Deleting

Consider:

- **Transfer ownership** - If you own organizations
- **Export data** - Save any reports you need
- **Notify team** - Let colleagues know
- **Alternative** - Consider just leaving organizations

## Troubleshooting

### Can't Access Account

If you can't log in:

- **Check email** - Ensure using correct address
- **Reset password** - Use forgot password flow
- **Verify email** - Check if verification needed
- **Contact support** - If locked out

### Email Already in Use

If you can't create account:

- You may already have an account
- Try password reset instead
- Check if you were invited previously

### Not Receiving Emails

If emails aren't arriving:

- Check spam/junk folders
- Verify email address is correct
- Whitelist Greendex domain
- Contact email provider

## Best Practices

### Security

- **Strong password** - Use unique, complex password
- **Regular changes** - Update password periodically
- **2FA enabled** - If available, use it
- **Monitor sessions** - Check active logins regularly

### Organization

- **Keep info current** - Update email if it changes
- **Profile complete** - Add picture and details
- **Right organization** - Ensure you're in correct context
- **Leave inactive** - Remove from old organizations

### Privacy

- **Minimal sharing** - Only necessary information
- **Review permissions** - Understand what others see
- **Data exports** - Know your data rights
- **GDPR rights** - Exercise if needed
