# Passwort vergessen

Wenn Sie Ihr Greendex-Kontopasswort vergessen haben, können Sie es einfach über unseren sicheren Passwort-Wiederherstellungsprozess zurücksetzen.

## Anfordern eines Passwort-Resets

### Schritt 1: Zugriff auf die Seite "Passwort vergessen"

1. Gehen Sie zur [Anmeldung](/docs/authentication/login)-Seite
2. Klicken Sie auf den Link **"Passwort vergessen?"** unter dem Anmeldeformular
3. Sie werden zur Seite für die Passwort-Reset-Anforderung weitergeleitet

### Schritt 2: Geben Sie Ihre E-Mail ein

1. Geben Sie die E-Mail-Adresse ein, die mit Ihrem Greendex-Konto verknüpft ist
2. Klicken Sie auf **"Reset-Link senden"**
3. Eine Bestätigungsnachricht wird angezeigt

### Schritt 3: Überprüfen Sie Ihre E-Mail

1. Öffnen Sie Ihren E-Mail-Posteingang
2. Suchen Sie nach einer E-Mail von Greendex mit dem Betreff "Passwort-Reset"
3. Wenn Sie sie nicht innerhalb weniger Minuten sehen, überprüfen Sie Ihren Spam/Junk-Ordner

### Schritt 4: Klicken Sie auf den Reset-Link

1. Öffnen Sie die Passwort-Reset-E-Mail
2. Klicken Sie auf die Schaltfläche oder den Link **"Passwort zurücksetzen"**
3. Sie werden zur Seite für den Passwort-Reset weitergeleitet

## Zurücksetzen Ihres Passworts

Sobald Sie auf den Reset-Link klicken, müssen Sie:

1. **Geben Sie ein neues Passwort ein** - Muss mindestens 6 Zeichen lang sein
2. **Bestätigen Sie das neue Passwort** - Geben Sie es erneut ein, um sicherzustellen, dass es übereinstimmt
3. **Klicken Sie auf "Passwort zurücksetzen"** - Ihr Passwort wird aktualisiert

Nach erfolgreichem Reset:

- Sie sehen eine Bestätigungsnachricht
- Sie werden zur Anmeldeseite weitergeleitet
- Verwenden Sie Ihr neues Passwort, um sich anzumelden

## Sicherheitsüberlegungen

### Passwortanforderungen

Ihr neues Passwort muss:

- Mindestens 6 Zeichen lang sein
- Nicht dasselbe wie Ihr vorheriges Passwort sein
- Einzigartig sein und nicht auf anderen Seiten verwendet werden

### Ablauf des Reset-Links

Passwort-Reset-Links laufen aus Sicherheitsgründen nach einer begrenzten Zeit ab. Wenn Ihr Link abgelaufen ist:

- Fordern Sie einen neuen Reset-Link an
- Der alte Link funktioniert nicht mehr

## Fehlerbehebung

### E-Mail nicht erhalten?

- **Überprüfen Sie Spam/Junk-Ordner** - Die E-Mail wurde möglicherweise gefiltert
- **Verifizieren Sie Ihre E-Mail-Adresse** - Stellen Sie sicher, dass Sie sie korrekt eingegeben haben
- **Warten Sie ein paar Minuten** - E-Mail-Zustellung kann manchmal verzögert sein
- **Versuchen Sie es erneut** - Fordern Sie bei Bedarf einen weiteren Reset-Link an

### Reset-Link funktioniert nicht?

- **Link abgelaufen** - Fordern Sie einen neuen Reset-Link an
- **Bereits verwendet** - Jeder Link kann nur einmal verwendet werden
- **Falsche E-Mail** - Stellen Sie sicher, dass Sie die richtige E-Mail-Adresse verwenden

### Immer noch Probleme?

Kontaktieren Sie Ihren Organisationsadministrator oder den Support für Hilfe bei der Kontowiederherstellung.
