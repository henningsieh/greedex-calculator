# Anmeldung

Greifen Sie auf Ihr Greendex-Konto zu, um Ihre Organisation und Projekte zu verwalten.

## Wie man sich anmeldet

1. Navigieren Sie zur Anmeldeseite
2. Geben Sie Ihre E-Mail-Adresse ein
3. Geben Sie Ihr Passwort ein
4. Klicken Sie auf "Anmelden"

## Soziale Anmeldung

Sie können sich auch anmelden mit:

- Google
- GitHub

## Fehlerbehebung

### Passwort vergessen

Wenn Sie Ihr Passwort vergessen haben, klicken Sie auf "Passwort vergessen" und folgen Sie den Anweisungen, um es zurückzusetzen.

### Konto nicht verifiziert

Wenn Sie Ihre E-Mail-Adresse nicht verifiziert haben, müssen Sie die Verifizierung abschließen, bevor Sie sich anmelden können.

## Nächste Schritte

Nach der Anmeldung werden Sie weitergeleitet zu:

- Dem Dashboard Ihrer Organisation (wenn Sie eine Organisation haben)
- Der Seite zur Organisationerstellung (wenn Sie noch keine Organisation haben)
