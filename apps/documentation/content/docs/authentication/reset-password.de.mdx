# Passwort zurücksetzen

Die Seite "Passwort zurücksetzen" ermöglicht es Ihnen, ein neues Passwort für Ihr Greendex-Konto zu erstellen, nachdem Sie einen Passwort-Reset angefordert haben.

## Wann Sie diese Seite verwenden

Sie gelangen zur Seite "Passwort zurücksetzen" nach:

- Klicken auf einen Passwort-Reset-Link aus Ihrer E-Mail
- Weiterleitung vom [Passwort vergessen](/docs/authentication/forgot-password)-Ablauf

## Wie Sie Ihr Passwort zurücksetzen

### Schritt 1: Token verifizieren

Die Reset-Seite validiert automatisch Ihr Reset-Token aus der URL. Wenn das Token:

- **Gültig** - Sie sehen das Passwort-Reset-Formular
- **Ungültig oder fehlend** - Sie werden zur Anmeldeseite weitergeleitet

### Schritt 2: Geben Sie Ihr neues Passwort ein

Füllen Sie das Passwort-Reset-Formular aus:

1. **Neues Passwort**
   - Geben Sie ein sicheres Passwort ein
   - Mindestens 6 Zeichen erforderlich
   - Verwenden Sie eine Mischung aus Buchstaben, Zahlen und Symbolen für bessere Sicherheit

2. **Neues Passwort bestätigen**
   - Geben Sie Ihr neues Passwort erneut ein
   - Muss genau mit dem Feld für das neue Passwort übereinstimmen

### Schritt 3: Formular absenden

Klicken Sie auf **"Passwort zurücksetzen"**, um den Prozess abzuschließen.

## Erfolg und nächste Schritte

Nach erfolgreichem Passwort-Reset:

1. Sie sehen eine Erfolgsbestätigungsnachricht
2. Sie werden automatisch zur [Anmeldung](/docs/authentication/login)-Seite weitergeleitet
3. Melden Sie sich mit Ihrer E-Mail und dem neuen Passwort an

## Fehlerbehandlung

### Passwort-Validierungsfehler

| Fehler                           | Lösung                                               |
| -------------------------------- | ---------------------------------------------------- |
| Passwort zu kurz                 | Verwenden Sie mindestens 6 Zeichen                   |
| Passwörter stimmen nicht überein | Stellen Sie sicher, dass beide Felder identisch sind |
| Bestätigung fehlt                | Füllen Sie das Feld "Passwort bestätigen" aus        |

### Token-Fehler

Wenn Sie eine Weiterleitung oder einen Fehler sehen:

- Der Reset-Link ist möglicherweise abgelaufen
- Das Token wurde möglicherweise bereits verwendet
- Sie müssen möglicherweise einen neuen Reset-Link anfordern

## Sicherheitsbest Practices

### Erstellen eines starken Passworts

- **Verwenden Sie 8+ Zeichen** - Länger ist besser
- **Mischen Sie Zeichentypen** - Großbuchstaben, Kleinbuchstaben, Zahlen, Symbole
- **Vermeiden Sie gängige Wörter** - Verwenden Sie keine Wörter aus dem Wörterbuch
- **Machen Sie es einzigartig** - Verwenden Sie keine Passwörter von anderen Seiten wieder
- **Verwenden Sie eine Passphrase** - Erwägen Sie eine einprägsame Phrase mit Modifikationen

### Passwortspeicherung

- Verwenden Sie einen Passwort-Manager, um Ihre Passwörter sicher zu speichern
- Schreiben Sie Passwörter niemals in Klartext auf
- Teilen Sie Ihr Passwort nicht mit anderen

## Fehlerbehebung

### "Ungültiges oder abgelaufenes Token"

Dieser Fehler tritt auf, wenn:

- Der Reset-Link älter als ein paar Stunden ist
- Sie den Link bereits zum Zurücksetzen Ihres Passworts verwendet haben
- Der Link fehlerhaft war

**Lösung**: Gehen Sie zurück zu [Passwort vergessen](/docs/authentication/forgot-password) und fordern Sie einen neuen Link an.

### Formular wird nicht abgesendet

- Stellen Sie sicher, dass beide Passwortfelder ausgefüllt sind
- Überprüfen Sie, dass die Passwörter genau übereinstimmen
- Verifizieren Sie, dass Ihr Passwort die Mindestlängenanforderung erfüllt

### Unerwartet zur Anmeldung weitergeleitet

Wenn Sie zur Anmeldeseite geschickt werden, anstatt das Reset-Formular zu sehen:

- Der Token-Parameter fehlt möglicherweise in der URL
- Das Token ist möglicherweise ungültig
- Fordern Sie einen neuen Passwort-Reset-Link an

## Verwandte Themen

- [Anmeldung](/docs/authentication/login) - Melden Sie sich mit Ihrem neuen Passwort an
- [Passwort vergessen](/docs/authentication/forgot-password) - Fordern Sie einen neuen Reset-Link an
