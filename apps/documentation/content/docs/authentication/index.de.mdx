# Authentifizierung

Greendex bietet ein sicheres Authentifizierungssystem, damit Benutzer auf ihre Konten zugreifen und ihre Organisationen verwalten können.

## Übersicht

Das Authentifizierungssystem umfasst:

- Benutzerregistrierung (Anmeldung)
- Anmeldung mit E-Mail/Passwort
- Passwort-Reset-Funktionalität
- E-Mail-Verifizierung
- Soziale Anmeldeanbieter (Google, GitHub)

## Authentifizierungsablauf

### Registrierung

Neue Benutzer können ein Konto erstellen, indem sie:

1. Die Registrierungsseite besuchen
2. E-Mail und Passwort angeben
3. Ihre E-Mail-Adresse verifizieren
4. Zur Erstellung einer Organisation weitergeleitet werden

### Anmeldung

Bestehende Benutzer können sich anmelden, indem sie:

1. Die Anmeldeseite besuchen
2. Ihre Anmeldedaten eingeben
3. Zu ihrem Dashboard weitergeleitet werden

### Passwort-Reset

Wenn ein Benutzer sein Passwort vergisst:

1. Klicken Sie auf "Passwort vergessen" auf der Anmeldeseite
2. Geben Sie ihre E-Mail-Adresse ein
3. Erhalten Sie einen Reset-Link per E-Mail
4. Erstellen Sie ein neues Passwort

## Sicherheitsfunktionen

- Sicheres Passwort-Hashing
- E-Mail-Verifizierung erforderlich
- Sitzungsverwaltung
- Geschützte Routen für authentifizierte Benutzer
