# E-Mail-Verifizierung

E-Mail-Verifizierung ist ein erforderlicher Schritt, um Ihr Greendex-Konto zu aktivieren und die Sicherheit Ihrer Organisationsdaten zu gewährleisten.

## Warum Verifizierung erforderlich ist

E-Mail-Verifizierung hilft:

- **Ihre Identität bestätigen** - Stellt sicher, dass Sie die E-Mail-Adresse besitzen
- **Ihr Konto sichern** - Verhindert unbefugten Zugriff
- **Kommunikation ermöglichen** - Ermöglicht uns, wichtige Benachrichtigungen zu senden
- **Ihre Daten schützen** - Fügt eine Sicherheitsebene zu Ihrer Organisation hinzu

## Der Verifizierungsprozess

### Nach der Registrierung

Wenn Sie ein neues Greendex-Konto erstellen:

1. **Überprüfen Sie Ihren Posteingang** - Suchen Sie nach einer E-Mail von Greendex
2. **Öffnen Sie die Verifizierungs-E-Mail** - Betreff: "Verifizieren Sie Ihre E-Mail-Adresse"
3. **Klicken Sie auf den Verifizierungslink** - Dies bestätigt Ihre E-Mail
4. **Konto aktiviert** - Sie sind bereit, Greendex zu verwenden

### Inhalt der Verifizierungs-E-Mail

Die E-Mail enthält:

- Eine personalisierte Begrüßung
- Eine **"E-Mail verifizieren"**-Schaltfläche/Link
- Informationen darüber, was als Nächstes passiert
- Support-Kontaktinformationen

## Verifizierungs-E-Mail erneut senden

Wenn Sie die Verifizierungs-E-Mail nicht erhalten haben oder sie abgelaufen ist:

### Von der E-Mail-Verifizierungsseite

1. Sie sehen die E-Mail-Verifizierungsseite unmittelbar nach der Registrierung
2. Ihre E-Mail-Adresse wird auf der Seite angezeigt
3. Klicken Sie auf **"E-Mail erneut senden"**, um einen neuen Verifizierungslink anzufordern

### Abkühlungszeit

Aus Sicherheitsgründen:

- Sie können die E-Mail nur alle 60 Sekunden erneut senden
- Ein Countdown-Timer zeigt an, wann Sie erneut senden können
- Der Versuch, während der Abkühlung erneut zu senden, zeigt eine Warnung

### Wenn E-Mail fehlt

Überprüfen Sie diese häufigen Probleme:

| Problem                | Lösung                                                                   |
| ---------------------- | ------------------------------------------------------------------------ |
| Spam/Junk-Ordner       | Überprüfen Sie den Spam- oder Junk-Ordner Ihrer E-Mail                   |
| Falsche E-Mail-Adresse | Gehen Sie zurück und überprüfen Sie die E-Mail, die Sie eingegeben haben |
| E-Mail-Verzögerung     | Warten Sie ein paar Minuten auf die Zustellung                           |
| Unternehmensfilter     | Kontaktieren Sie Ihre IT-Abteilung bezüglich Whitelist                   |

## Verhalten des Verifizierungslinks

### Erfolgreiche Verifizierung

Wenn Sie auf einen gültigen Verifizierungslink klicken:

- Ihre E-Mail wird als verifiziert markiert
- Ihr Konto wird vollständig aktiviert
- Sie werden zur Anmeldeseite weitergeleitet
- Sie können sich jetzt anmelden und eine Organisation erstellen

### Ungültige oder abgelaufene Links

Wenn der Verifizierungslink nicht funktioniert:

- **Abgelaufen** - Links laufen aus Sicherheitsgründen nach einer festgelegten Zeit ab
- **Bereits verwendet** - Jeder Link kann nur einmal verwendet werden
- **Falsche E-Mail** - Der Link ist an eine bestimmte E-Mail-Adresse gebunden

**Lösung**: Fordern Sie eine neue Verifizierungs-E-Mail von der E-Mail-Verifizierungsseite an.

## Fehlerbehebung

### Keine E-Mail erhalten

1. **Warten Sie 5 Minuten** - Manchmal dauert die Zustellung
2. **Überprüfen Sie alle Ordner** - Einschließlich Spam, Junk, Promotions
3. **E-Mail-Adresse verifizieren** - Stellen Sie sicher, dass Sie sie korrekt bei der Registrierung eingegeben haben
4. **Versuchen Sie erneut zu senden** - Verwenden Sie die Schaltfläche "Erneut senden" nach der Abkühlung
5. **Support kontaktieren** - Wenn Probleme bestehen bleiben

### "E-Mail bereits verifiziert"

Wenn Sie diese Nachricht sehen:

- Ihre E-Mail ist bereits verifiziert
- Sie können mit der Anmeldung fortfahren
- Keine weitere Aktion erforderlich

### Kann nicht auf E-Mail-Konto zugreifen

Wenn Sie den Zugriff auf die E-Mail verlieren, mit der Sie sich angemeldet haben:

- Kontaktieren Sie Ihren Organisationsadministrator
- Möglicherweise müssen Sie ein neues Konto mit einer anderen E-Mail erstellen
- Aktualisieren Sie die E-Mail in den Benutzereinstellungen, wenn Sie den Zugriff wiedererlangen

## Nach der Verifizierung

Sobald Ihre E-Mail verifiziert ist:

1. **Anmelden** - Verwenden Sie Ihre Anmeldedaten, um auf Greendex zuzugreifen
2. **Organisation erstellen** - Richten Sie Ihre erste Organisation ein
3. **Team einladen** - Fügen Sie Kollegen hinzu, um Projekte zu verwalten
4. **Beginnen Sie mit der Verfolgung** - Beginnen Sie mit der Erstellung von Projekten und der Verfolgung des CO2-Fußabdrucks

## Sicherheitshinweise

### Best Practices für E-Mail-Verifizierung

- **Verwenden Sie eine persönliche E-Mail** - Eine, auf die Sie langfristig Zugriff haben
- **Halten Sie E-Mail sicher** - Schützen Sie das E-Mail-Konto mit starken Passwörtern
- **Aktualisieren Sie bei Bedarf** - Ändern Sie Ihre E-Mail in den Einstellungen, wenn sich Umstände ändern
- **Achten Sie auf Phishing** - Klicken Sie nur auf Links aus offiziellen Greendex-E-Mails

### Legitime E-Mails erkennen

Echte Greendex-E-Mails:

- Kommen von offiziellen Greendex-Domains
- Enthalten Ihren Namen und Registrierungsdetails
- Fragen niemals nach Ihrem Passwort
- Haben professionelle Formatierung
