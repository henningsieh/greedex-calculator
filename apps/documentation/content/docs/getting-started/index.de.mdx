# Erste Schritte

Willkommen bei Greendex! Diese Anleitung hilft Ihnen, den CO2-Fußabdruck-Rechner in Betrieb zu nehmen.

## Übersicht

Greendex wurde entwickelt, um Erasmus+-Organisationen dabei zu helfen, ihren CO2-Fußabdruck zu verfolgen und zu reduzieren. Die Anwendung besteht aus mehreren Schlüsselbereichen:

1. **Startseite** - Öffentliche Informationen über Greendex
2. **Authentifizierung** - Benutzerkontoverwaltung
3. **Organisationseinrichtung** - Erstellen Sie Ihre Organisation
4. **App-Kern** - Projekt- und Teilnehmermanagement
5. **Öffentliche Teilnahme** - Formulare für Teilnehmer zur Dateneinreichung

## Erste Schritte

### 1. Konto erstellen

Um mit Greendex zu beginnen, müssen Sie ein Konto erstellen:

1. Besuchen Sie die Registrierungsseite
2. Geben Sie Ihre E-Mail-Adresse ein und erstellen Sie ein Passwort
3. Verifizieren Sie Ihre E-Mail-Adresse
4. Melden Sie sich in Ihrem Konto an

### 2. Organisation erstellen

Nach der Anmeldung müssen Sie eine Organisation erstellen:

1. Geben Sie den Namen Ihrer Organisation ein
2. Geben Sie alle erforderlichen Details an
3. Ihre Organisation ist nun einsatzbereit

### 3. Teammitglieder einladen

Sie können Teammitglieder einladen, um bei der Verwaltung Ihrer Organisation zu helfen:

1. Gehen Sie zur Team-Seite
2. Klicken Sie auf "Mitglied einladen"
3. Geben Sie ihre E-Mail-Adresse ein und wählen Sie eine Rolle
4. Sie erhalten eine Einladungs-E-Mail

### 4. Erstellen Sie Ihr erstes Projekt

Jetzt sind Sie bereit, ein Projekt zu erstellen:

1. Navigieren Sie zur Projekte-Seite
2. Klicken Sie auf "Projekt erstellen"
3. Füllen Sie die Projektdetails aus
4. Ihr Projekt ist bereit für Teilnehmer

## Nächste Schritte

- Erfahren Sie mehr über [Organisationsmanagement](/docs/organization)
- Verstehen Sie [Projekterstellung](/docs/projects/create)
- Richten Sie [Teilnehmersammlung](/docs/participation) ein
