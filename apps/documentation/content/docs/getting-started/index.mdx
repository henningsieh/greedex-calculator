# Getting Started

Welcome to Greendex! This guide will help you get up and running with the carbon footprint calculator.

## Overview

Greendex is designed to help Erasmus+ organizations track and reduce their carbon footprint. The application consists of several key areas:

1. **Landing Page** - Public information about Greendex
2. **Authentication** - User account management
3. **Organization Setup** - Create your organization
4. **App Core** - Project and participant management
5. **Public Participation** - Forms for participants to submit data

## First Steps

### 1. Create an Account

To get started with Greendex, you'll need to create an account:

1. Visit the signup page
2. Enter your email and create a password
3. Verify your email address
4. Log in to your account

### 2. Create an Organization

After logging in, you'll need to create an organization:

1. Enter your organization name
2. Provide any required details
3. Your organization is now ready to use

### 3. Invite Team Members

You can invite team members to help manage your organization:

1. Go to the Team page
2. Click "Invite Member"
3. Enter their email and select a role
4. They'll receive an invitation email

### 4. Create Your First Project

Now you're ready to create a project:

1. Navigate to the Projects page
2. Click "Create Project"
3. Fill in the project details
4. Your project is ready for participants
