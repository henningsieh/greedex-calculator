# Participant Management

The Participants page provides tools to view, manage, and organize all participants across your organization's projects.

## Accessing Participants

Navigate to the Participants section:

1. Click **"Participants"** in the main sidebar
2. You'll see a list of all organization participants
3. Use filters and search to find specific participants

## Participants List

### Table View

The participants table displays:

| Column       | Description                        |
| ------------ | ---------------------------------- |
| **Name**     | Participant's full name            |
| **Email**    | Contact email address              |
| **Country**  | Origin country                     |
| **Projects** | Number of associated projects      |
| **Status**   | Registration and submission status |
| **Actions**  | Available management options       |

### Status Indicators

Visual badges show participant status:

- 🟢 **Active** - Currently participating in projects
- 🔵 **Completed** - Finished participation
- 🟡 **Pending** - Invited but not yet active
- ⚪ **Inactive** - No current project associations

## Filtering and Searching

### Search

Find participants by:

- **Name** - First or last name
- **Email** - Email address
- **Country** - Origin country

### Filters

Filter the participant list:

#### By Status

- All participants
- Active only
- Pending invitations
- Completed
- Inactive

#### By Project

- Participants in specific projects
- Cross-project participants
- Unassigned participants

#### By Country

- Filter by origin country
- Useful for regional analysis
- Group by geographic regions

### Sorting

Order participants by:

- **Name** - Alphabetical
- **Country** - Grouped by origin
- **Join date** - When they first participated
- **Project count** - Most to least active

## Participant Details

### Viewing Individual Participants

Click on a participant to see:

- **Personal information** - Name, email, country
- **Project history** - All projects they've participated in
- **Submission data** - Carbon footprint information
- **Activity log** - Registration and submission history

### Participant Profile

The profile view shows:

#### Basic Information

- Full name
- Email address
- Country of origin
- Account creation date

#### Project Associations

List of projects:

- Project name and dates
- Role in project
- Submission status per project
- Carbon data submitted

#### Carbon Footprint Summary

- Total emissions across all projects
- Average per project
- Transport mode preferences
- Trend over time

## Managing Participants

### Editing Participant Information

To update participant details:

1. Find the participant in the list
2. Click **"Edit"** or the participant name
3. Modify the fields
4. Save changes

**Editable fields:**

- Name (corrections)
- Email (if changed)
- Country (if incorrect)

**Note:** Some fields may be locked if the participant has an active account.

### Removing Participants

To remove a participant:

1. Find the participant in the list
2. Click **"Remove"** button
3. Confirm the action

**What happens:**

- Participant is removed from the organization
- Their data remains in projects (for reporting)
- They lose access to any associated accounts
- Can be re-invited later if needed

**Caution:** This action cannot be undone.

### Merging Duplicate Participants

If the same person appears multiple times:

1. Identify duplicate entries
2. Select the primary record
3. Use **"Merge"** function (if available)
4. Choose which data to keep
5. Confirm the merge

**Best practice:** Prevent duplicates by using consistent email addresses.

## Participant Data Management

### Exporting Data

Download participant information:

1. Select participants (or use filters)
2. Click **"Export"** button
3. Choose format:
   - **CSV** - For spreadsheets
   - **PDF** - For reports
   - **JSON** - For integrations
4. Download the file

**Export includes:**

- Personal information
- Project associations
- Carbon footprint data
- Submission dates

### Importing Participants

Bulk import participants (if feature enabled):

1. Prepare CSV file with required columns
2. Go to Participants page
3. Click **"Import"**
4. Upload the file
5. Map columns to fields
6. Review and confirm

**Required columns:**

- Name
- Email
- Country
- Project (optional)

### Data Validation

The system validates participant data:

- **Email format** - Must be valid email
- **Required fields** - Name cannot be empty
- **Country codes** - Must be valid ISO codes
- **Duplicates** - Warns if email already exists

## Communication

### Contacting Participants

Send messages to participants:

1. Select participants (or filter group)
2. Click **"Contact"** or **"Email"**
3. Compose message
4. Send or schedule

**Use cases:**

- Reminder to submit carbon data
- Project updates
- Thank you messages
- Follow-up surveys

### Email Templates

Use templates for common communications:

- **Submission reminder** - Prompt to complete form
- **Deadline approaching** - Urgent reminder
- **Thank you** - Acknowledge participation
- **Project update** - Share information

## Best Practices

### Data Quality

- **Verify emails** - Ensure contactability
- **Standardize names** - Consistent formatting
- **Correct countries** - Accurate for statistics
- **Remove duplicates** - Keep data clean

### Privacy Compliance

- **Minimal data** - Collect only what's needed
- **Secure storage** - Protect personal information
- **Access control** - Limit who can view data
- **Retention limits** - Delete when no longer needed
- **Consent records** - Document permissions

### Engagement

- **Welcome message** - Acknowledge new participants
- **Regular updates** - Keep them informed
- **Show impact** - Share carbon footprint results
- **Solicit feedback** - Improve future projects

## Troubleshooting

### Participant Not Found

If a participant doesn't appear:

- Check filter settings
- Verify spelling in search
- Look in specific project
- Check if they were removed

### Can't Edit Participant

If editing is disabled:

- May have active account
- Insufficient permissions
- Data is locked
- Contact an Owner

### Export Fails

If export doesn't work:

- Check selected participants
- Try smaller batches
- Verify file format
- Check browser download settings
