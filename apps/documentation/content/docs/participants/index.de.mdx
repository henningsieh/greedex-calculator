# Teilnehmerübersicht

Teilnehmer sind Personen, die an Ihren Erasmus+-Projekten teilnehmen und ihre CO2-Fußabdruck-Daten über das Teilnahmeformular einreichen.

## Was ist ein Teilnehmer?

In Greendex ist ein **Teilnehmer**:

- Jemand, der an Ihrer Erasmus+-Aktivität teilnimmt (Jugendaustausch, Schulung, Treffen)
- Eine Person, die Reise- und CO2-Fußabdruck-Informationen einreicht
- Mit bestimmten Projekten in Ihrer Organisation verbunden
- Hat eingeschränkten Zugriff auf die Greendex-Plattform

## Teilnehmer vs. Teammitglied

Es ist wichtig, zwischen zu unterscheiden:

| Aspekt             | Teilnehmer                          | Benutzer (Organisationsadministrator/Projektkoordinator) |
| ------------------ | ----------------------------------- | -------------------------------------------------------- |
| **Zugriff**        | Eingeschränkt auf Teilnahmeformular | Vollständiger Plattformzugriff                           |
| **Rolle**          | Nimmt an Projekten teil             | Verwaltet Projekte                                       |
| **Berechtigungen** | Eigene CO2-Daten einreichen         | Alle Projektdaten verwalten                              |
| **Einladung**      | Über Projektteilnahme               | Über Teameinladungen                                     |
| **Konto**          | Kann Login haben oder nicht         | Hat vollständiges Benutzerkonto                          |

## Wie Teilnehmer beitreten

### Über öffentliches Teilnahmeformular

Der häufigste Weg:

1. Organisator teilt Projektteilnahme-Link
2. Teilnehmer besucht das öffentliche Formular
3. Füllt persönliche und Reiseinformationen aus
4. Reicht CO2-Fußabdruck-Daten ein
5. Wird automatisch zum Projekt hinzugefügt

### Über Teameinladung

Teilnehmer können auch eingeladen werden:

1. Organisationsadministrator oder Projektkoordinator sendet Einladung
2. Teilnehmer erhält E-Mail
3. Erstellt Konto (falls nötig)
4. Tritt als Teilnehmer-Rolle bei
5. Kann auf zugewiesene Projekte zugreifen

## Teilnehmerdaten

### Was wir sammeln

Teilnehmer geben an:

#### Persönliche Informationen

- **Name** - Vollständiger Name zur Identifizierung
- **E-Mail** - Kontakt- und Kontozwecke
- **Land** - Herkunftsland für Statistiken

#### Reiseinformationen

- **Transportmittel** - Flugzeug, Zug, Bus, Auto
- **Abreiseort** - Woher sie gereist sind
- **Ankunftsort** - Projektort
- **Entfernung** - Berechnet oder angegeben
- **Reisende** - Anzahl der Personen (für gemeinsamen Transport)

#### Zusätzliche Informationen

- **Ernährungsvorlieben** - Für CO2-Berechnungen
- **Unterkunft** - Art der Unterkunft
- **Besondere Anforderungen** - Barrierefreiheitsbedürfnisse

### Datennutzung

Teilnehmerdaten werden verwendet für:

- **CO2-Fußabdruck-Berechnung** - Hauptzweck
- **Projektstatistiken** - Aggregierte Berichterstattung
- **Organisationseinblicke** - Trendanalyse
- **Förderberichterstattung** - Erforderliche Dokumentation

### Datenschutz

Greendex schützt Teilnehmerdaten:

- **DSGVO-konform** - Europäische Datenschutzstandards
- **Verschlüsselte Speicherung** - Sichere Datenbankspeicherung
- **Zugriffskontrollen** - Nur autorisierte Teammitglieder
- **Aufbewahrungsrichtlinien** - Daten nur so lange wie nötig aufbewahrt

## Teilnehmerlebenszyklus

### 1. Registrierung

Teilnehmer wird dem System bekannt:

- Besucht Teilnahmeformular
- Gibt persönliche Informationen ein
- Erstellt einen Teilnehmerdatensatz
- Wird mit dem Projekt verbunden

### 2. Dateneinreichung

Teilnehmer reicht CO2-Informationen ein:

- Gibt Reisedetails ein
- Gibt Transportinformationen an
- Sendet das Formular
- Daten werden validiert und gespeichert

### 3. Teilnahme

Während des Projekts:

- Daten erscheinen im Projekt-Dashboard
- In Statistiken eingeschlossen
- Kann Einreichung aktualisieren (falls aktiviert)
- Für Projektorganisatoren sichtbar

### 4. Abschluss

Nach dem Projekt:

- Daten in Endberichten eingeschlossen
- Teilnehmerdatensatz archiviert
- Kann zu zukünftigen Projekten eingeladen werden
- Konto bleibt, falls erstellt

## Teilnehmer verwalten

### Teilnehmer anzeigen

Zugriff auf Teilnehmerinformationen:

1. Gehen Sie zu **Teilnehmer** in der Seitenleiste
2. Sehen Sie Liste aller Organisationsteilnehmer
3. Oder sehen Sie projektbezogene Teilnehmer in Projektdetails

### Teilnehmerinformationen

Verfügbare Daten umfassen:

- Persönliche Details (Name, E-Mail, Land)
- Projektverbindungen
- Einreichungsstatus
- CO2-Fußabdruck-Gesamtsummen
- Aktivitätsverlauf

### Aktionen

Organisatoren können:

- **Details anzeigen** - Teilnehmerinformationen sehen
- **Daten bearbeiten** - Fehler korrigieren (mit Berechtigungen)
- **Entfernen** - Teilnehmer aus Projekt löschen
- **Exportieren** - Teilnehmerdaten herunterladen
- **Kontaktieren** - Kommunikation senden

## Teilnehmerstatus

### Registrierungsstatus

| Status                                                      | Beschreibung |
| ----------------------------------------------------------- | ------------ |
| **Eingeladen** - Einladung gesendet, noch nicht geantwortet |
| **Registriert** - Konto erstellt oder Formular ausgefüllt   |
| **Aktiv** - Nimmt derzeit teil                              |
| **Abgeschlossen** - Teilnahme beendet                       |
| **Zurückgezogen** - Projekt verlassen                       |

### Einreichungsstatus

| Status                                                       | Beschreibung |
| ------------------------------------------------------------ | ------------ |
| **Nicht eingereicht** - Noch keine CO2-Daten                 |
| **Teilweise** - Einige Informationen angegeben               |
| **Eingereicht** - Vollständige Daten erhalten                |
| **Validiert** - Daten geprüft und genehmigt                  |
| **Überprüfung erforderlich** - Potenzielle Probleme markiert |

## Best Practices

### Für Organisatoren

#### Vor dem Projekt

- **Link früh teilen** - Teilnehmern Zeit zum Antworten geben
- **Anweisungen geben** - Erklären, was benötigt wird
- **Frist setzen** - Klare Einreichungsfrist
- **Erinnerungen senden** - Nachfassen bei Nicht-Einreichern

#### Während der Datensammlung

- **Fortschritt überwachen** - Einreichungsraten prüfen
- **Teilnehmer helfen** - Bei Fragen assistieren
- **Daten validieren** - Auf Fehler oder Ausreißer prüfen
- **Nachfassen** - Fehlende Teilnehmer kontaktieren

#### Nach Abschluss

- **Teilnehmer danken** - Ihren Beitrag anerkennen
- **Ergebnisse teilen** - CO2-Fußabdruck-Gesamtsummen zeigen
- **Daten archivieren** - Für erforderliche Zeiträume speichern
- **Verbesserungen planen** - Einblicke für das nächste Mal nutzen

### Für Teilnehmer

#### Formular ausfüllen

- **Seien Sie genau** - Korrekte Informationen gewährleisten gültige Berechnungen
- **Alle Reisen einschließen** - Rückreisen nicht vergessen
- **Schätzen Sie bei Bedarf** - Ungefähre Entfernungen sind akzeptabel
- **Früh einreichen** - Nicht bis zur Frist warten

#### Datenschutz

- **Ihre Rechte kennen** - DSGVO-Schutz verstehen
- **Fragen stellen** - Organisatoren bei Bedenken kontaktieren
- **Bei Bedarf aktualisieren** - Fehler prompt korrigieren
- **Einwilligung zählt** - Stellen Sie sicher, dass Sie der Datennutzung zustimmen

## Fehlerbehebung

### Teilnehmer kann nicht auf Formular zugreifen

Wenn das Teilnahmeformular nicht funktioniert:

- **Link prüfen** - Stellen Sie sicher, dass es die richtige URL ist
- **Projekt verifizieren** - Bestätigen Sie, dass das Projekt aktiv ist
- **Versuchen Sie anderen Browser** - Browser-Kompatibilitätsprobleme
- **Organisator kontaktieren** - Technische Probleme melden

### Daten erscheinen nicht

Wenn Teilnehmereinreichungen nicht sichtbar sind:

- **Einreichung prüfen** - Verifizieren Sie, dass das Formular eingereicht wurde
- **Kurz warten** - Daten können Momente zum Synchronisieren brauchen
- **Seite aktualisieren** - Neu laden, um Updates zu sehen
- **Filter prüfen** - Stellen Sie sicher, dass nicht herausgefiltert

### Falsche Informationen

Wenn Teilnehmerdaten falsch sind:

- **Kann bearbeiten** - Einige Felder können aktualisiert werden
- **Organisator kontaktieren** - Korrekturen anfordern
- **Erneut einreichen** - Formular bei Bedarf erneut ausfüllen
- **Änderungen dokumentieren** - Aufzeichnung der Korrekturen behalten
