# Teilnehmermanagement

Die Teilnehmer-Seite bietet Tools zum Anzeigen, Verwalten und Organisieren aller Teilnehmer in den Projekten Ihrer Organisation.

## Zugriff auf Teilnehmer

Navigieren Sie zum Teilnehmer-Abschnitt:

1. Klicken Sie auf **"Teilnehmer"** in der Hauptseitenleiste
2. Sie sehen eine Liste aller Organisationsteilnehmer
3. Verwenden Sie Filter und Suche, um bestimmte Teilnehmer zu finden

## Teilnehmerliste

### Tabellenansicht

Die Teilnehmertabelle zeigt:

| Spalte       | Beschreibung                           |
| ------------ | -------------------------------------- |
| **Name**     | Vollständiger Name des Teilnehmers     |
| **E-Mail**   | Kontakt-E-Mail-Adresse                 |
| **Land**     | Herkunftsland                          |
| **Projekte** | Anzahl der verbundenen Projekte        |
| **Status**   | Registrierungs- und Einreichungsstatus |
| **Aktionen** | Verfügbare Verwaltungsoptionen         |

### Status-Indikatoren

Visuelle Badges zeigen den Teilnehmerstatus:

- 🟢 **Aktiv** - Nimmt derzeit an Projekten teil
- 🔵 **Abgeschlossen** - Teilnahme beendet
- 🟡 **Ausstehend** - Eingeladen, aber noch nicht aktiv
- ⚪ **Inaktiv** - Keine aktuellen Projektverbindungen

## Filtern und Suchen

### Suche

Teilnehmer finden nach:

- **Name** - Vor- oder Nachname
- **E-Mail** - E-Mail-Adresse
- **Land** - Herkunftsland

### Filter

Die Teilnehmerliste filtern:

#### Nach Status

- Alle Teilnehmer
- Nur aktive
- Ausstehende Einladungen
- Abgeschlossen
- Inaktiv

#### Nach Projekt

- Teilnehmer in bestimmten Projekten
- Teilnehmer über Projekte hinweg
- Nicht zugewiesene Teilnehmer

#### Nach Land

- Nach Herkunftsland filtern
- Nützlich für regionale Analyse
- Nach geografischen Regionen gruppieren

### Sortierung

Teilnehmer ordnen nach:

- **Name** - Alphabetisch
- **Land** - Nach Herkunft gruppiert
- **Beitrittsdatum** - Wann sie zuerst teilgenommen haben
- **Projektanzahl** - Von aktivsten zu wenigsten

## Teilnehmerdetails

### Einzelne Teilnehmer anzeigen

Klicken Sie auf einen Teilnehmer, um zu sehen:

- **Persönliche Informationen** - Name, E-Mail, Land
- **Projektverlauf** - Alle Projekte, an denen sie teilgenommen haben
- **Einreichungsdaten** - CO2-Fußabdruck-Informationen
- **Aktivitätsprotokoll** - Registrierungs- und Einreichungsverlauf

### Teilnehmerprofil

Die Profilansicht zeigt:

#### Grundinformationen

- Vollständiger Name
- E-Mail-Adresse
- Herkunftsland
- Kontenerstellungsdatum

#### Projektverbindungen

Liste der Projekte:

- Projektname und Daten
- Rolle im Projekt
- Einreichungsstatus pro Projekt
- Eingereichte CO2-Daten

#### CO2-Fußabdruck-Zusammenfassung

- Gesamtemissionen über alle Projekte
- Durchschnitt pro Projekt
- Transportmittel-Präferenzen
- Trend über Zeit

## Teilnehmer verwalten

### Teilnehmerinformationen bearbeiten

Um Teilnehmerdetails zu aktualisieren:

1. Finden Sie den Teilnehmer in der Liste
2. Klicken Sie auf **"Bearbeiten"** oder den Teilnehmernamen
3. Ändern Sie die Felder
4. Änderungen speichern

**Bearbeitbare Felder:**

- Name (Korrekturen)
- E-Mail (falls geändert)
- Land (falls falsch)

**Hinweis:** Einige Felder können gesperrt sein, wenn der Teilnehmer ein aktives Konto hat.

### Teilnehmer entfernen

Um einen Teilnehmer zu entfernen:

1. Finden Sie den Teilnehmer in der Liste
2. Klicken Sie auf die Schaltfläche **"Entfernen"**
3. Bestätigen Sie die Aktion

**Was passiert:**

- Teilnehmer wird aus der Organisation entfernt
- Ihre Daten bleiben in Projekten (für Berichterstattung)
- Sie verlieren Zugriff auf verbundene Konten
- Kann später bei Bedarf erneut eingeladen werden

**Vorsicht:** Diese Aktion kann nicht rückgängig gemacht werden.

### Doppelte Teilnehmer zusammenführen

Wenn dieselbe Person mehrmals erscheint:

1. Doppelte Einträge identifizieren
2. Primären Datensatz auswählen
3. **"Zusammenführen"**-Funktion verwenden (falls verfügbar)
4. Wählen Sie, welche Daten behalten werden sollen
5. Zusammenführung bestätigen

**Best Practice:** Duplikate verhindern, indem konsistente E-Mail-Adressen verwendet werden.

## Teilnehmerdatenverwaltung

### Daten exportieren

Teilnehmerinformationen herunterladen:

1. Teilnehmer auswählen (oder Filter verwenden)
2. Klicken Sie auf die Schaltfläche **"Exportieren"**
3. Format wählen:
   - **CSV** - Für Tabellenkalkulationen
   - **PDF** - Für Berichte
   - **JSON** - Für Integrationen
4. Datei herunterladen

**Export umfasst:**

- Persönliche Informationen
- Projektverbindungen
- CO2-Fußabdruck-Daten
- Einreichungsdaten

### Teilnehmer importieren

Massenimport von Teilnehmern (falls Funktion aktiviert):

1. CSV-Datei mit erforderlichen Spalten vorbereiten
2. Zur Teilnehmer-Seite gehen
3. Klicken Sie auf **"Importieren"**
4. Datei hochladen
5. Spalten Feldern zuordnen
6. Überprüfen und bestätigen

**Erforderliche Spalten:**

- Name
- E-Mail
- Land
- Projekt (optional)

### Datenvalidierung

Das System validiert Teilnehmerdaten:

- **E-Mail-Format** - Muss gültige E-Mail sein
- **Erforderliche Felder** - Name kann nicht leer sein
- **Länder-Codes** - Müssen gültige ISO-Codes sein
- **Duplikate** - Warnt, wenn E-Mail bereits existiert

## Kommunikation

### Teilnehmer kontaktieren

Nachrichten an Teilnehmer senden:

1. Teilnehmer auswählen (oder Gruppe filtern)
2. Klicken Sie auf **"Kontaktieren"** oder **"E-Mail"**
3. Nachricht verfassen
4. Senden oder planen

**Anwendungsfälle:**

- Erinnerung, CO2-Daten einzureichen
- Projektaktualisierungen
- Dankesnachrichten
- Nachbefragungen

### E-Mail-Vorlagen

Vorlagen für häufige Kommunikationen verwenden:

- **Einreichungserinnerung** - Aufforderung, Formular zu vervollständigen
- **Frist nähert sich** - Dringende Erinnerung
- **Danke** - Teilnahme anerkennen
- **Projektaktualisierung** - Informationen teilen

## Teilnehmeranalytik

### Übersichtsstatistiken

Angezeigte Zusammenfassungsmetriken:

- **Gesamtteilnehmer** - Organisationslebenszeit
- **Aktive Teilnehmer** - Derzeit in Projekten
- **Vertretene Länder** - Geografische Vielfalt
- **Durchschnittsprojekte** - Pro Teilnehmer

### Trends

Visuelle Analytik zeigt:

- **Teilnahme über Zeit** - Monatliche/vierteljährliche Trends
- **Länderverteilung** - Woher Teilnehmer kommen
- **Projektpopularität** - Meist beigetretene Projekte
- **Bindungsrate** - Wiederkehrende Teilnehmer

### CO2-Fußabdruck nach Teilnehmer

Analysetools:

- **Höchste Emittenten** - Für Ausgleichsprogramme identifizieren
- **Niedrigste Emittenten** - Nachhaltige Reisen anerkennen
- **Durchschnitt pro Teilnehmer** - Benchmark-Metrik
- **Transportpräferenzen** - Modal-Split nach Teilnehmer

## Best Practices

### Datenqualität

- **E-Mails verifizieren** - Kontaktierbarkeit sicherstellen
- **Namen standardisieren** - Konsistente Formatierung
- **Länder korrigieren** - Genau für Statistiken
- **Duplikate entfernen** - Daten sauber halten

### Datenschutzkonformität

- **Minimale Daten** - Nur sammeln, was benötigt wird
- **Sichere Speicherung** - Persönliche Informationen schützen
- **Zugriffskontrolle** - Begrenzen, wer Daten anzeigen kann
- **Aufbewahrungsgrenzen** - Löschen, wenn nicht mehr benötigt
- **Einwilligungsaufzeichnungen** - Berechtigungen dokumentieren

### Engagement

- **Willkommensnachricht** - Neue Teilnehmer anerkennen
- **Regelmäßige Updates** - Sie informiert halten
- **Auswirkungen zeigen** - CO2-Fußabdruck-Ergebnisse teilen
- **Feedback einholen** - Zukünftige Projekte verbessern

## Fehlerbehebung

### Teilnehmer nicht gefunden

Wenn ein Teilnehmer nicht erscheint:

- Filtereinstellungen prüfen
- Rechtschreibung in Suche verifizieren
- In spezifischem Projekt suchen
- Prüfen, ob sie entfernt wurden

### Kann Teilnehmer nicht bearbeiten

Wenn Bearbeitung deaktiviert ist:

- Kann aktives Konto haben
- Unzureichende Berechtigungen
- Daten sind gesperrt
- Einen Eigentümer kontaktieren

### Export schlägt fehl

Wenn Export nicht funktioniert:

- Ausgewählte Teilnehmer prüfen
- Kleinere Batches versuchen
- Dateiformat verifizieren
- Browser-Download-Einstellungen prüfen
