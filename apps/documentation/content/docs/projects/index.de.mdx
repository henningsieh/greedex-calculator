# Projekte

Projekte repräsentieren individuelle Erasmus+-Aktivitäten (Jugendaustausche, Schulungen, Treffen), für die Sie CO2-Fußabdruck-Daten verfolgen möchten.

## Was ist ein Projekt?

Ein Projekt in Greendex enthält:

- **Projektdetails** - Name, Beschreibung, Daten, Standort
- **Teilnehmer** - Personen, die an der Aktivität teilnehmen
- **CO2-Daten** - Reiseinformationen und Emissionsberechnungen
- **Status** - Aktiv, abgeschlossen oder archiviert

## Projektlebenszyklus

1. **Erstellen** - Ein neues Projekt mit grundlegenden Informationen einrichten
2. **Einladen** - Teilnehmer zum Projekt hinzufügen
3. **Sammeln** - CO2-Fußabdruck-Daten von Teilnehmern sammeln
4. **Überwachen** - Einreichungen in Echtzeit verfolgen
5. **Archivieren** - Projekt abschließen, wenn fertig

## Projekttypen

Greendex unterstützt die Verfolgung des CO2-Fußabdrucks für verschiedene Erasmus+-Aktivitäten:

- Jugendaustausche
- Schulungen
- Netzwerktreffen
- Job Shadowing
- Freiwilligenaktivitäten
