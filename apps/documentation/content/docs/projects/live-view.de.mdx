# Live-Ansicht

Die Live-Ansicht bietet Echtzeit-Überwachung aktiver Projekte, zeigt Teilnehmereinreichungen, CO2-Fußabdruck-Statistiken und Engagement-Metriken in Echtzeit.

## Was ist Live-Ansicht?

Live-Ansicht ist ein Dashboard für Projektorganisatoren, um:

- **Teilnahme in Echtzeit überwachen**
- **CO2-Daten-Einreichungen verfolgen**, wenn sie ankommen
- **Statistik-Updates sofort anzeigen**
- **Teilnehmer-Engagement-Metriken sehen**
- **Trends während der Datensammlungsperiode identifizieren**

## Zugriff auf Live-Ansicht

### Von Projektdetails

1. Gehen Sie zur Detailseite eines Projekts
2. Klicken Sie auf die Schaltfläche **"Live-Ansicht"**
3. Das Live-Dashboard öffnet sich

### Von Seitenleiste

Wenn Live-Ansicht für Ihre Organisation aktiviert ist:

1. Suchen Sie nach **"Live-Ansicht"** in der Seitenleiste
2. Klicken Sie, um auf das Dashboard zuzugreifen
3. Wählen Sie das zu überwachende Projekt aus

## Live-Ansicht-Komponenten

### Echtzeit-Indikator

Ein visueller Indikator zeigt:

- 🟢 **Live** - Verbunden und empfängt Updates
- 🟡 **Verbinde** - Verbindung wird hergestellt
- 🔴 **Getrennt** - Verbindung verloren, versuche Neuverbindung

### Statistikübersicht

Schlüsselmetriken in Echtzeit angezeigt:

#### Gesamtteilnehmer

- Aktuelle Anzahl registrierter Teilnehmer
- Aktualisiert, wenn neue Personen beitreten
- Zeigt Wachstumstrend

#### Einreichungsrate

- Prozentsatz, die CO2-Daten eingereicht haben
- Aktualisiert mit jeder neuen Einreichung
- Zielindikator für Ziele

#### Gesamt-CO2-Emissionen

- Laufende Summe aller Emissionen
- Aktualisiert sofort bei neuen Einreichungen
- Zeigt Vergleich zu Projektionen

#### Durchschnitt pro Teilnehmer

- Mittlerer CO2-Fußabdruck
- Aktualisiert mit jeder Einreichung
- Hilft, Ausreißer zu identifizieren

### Bestenliste

Eine rangierte Liste zeigt:

- **Top-Teilnehmer** nach verschiedenen Metriken
- **Vertretene Länder** - Herkunft der Teilnehmer
- **Transportwahl** - Beliebteste Methoden
- **Kürzliche Einreichungen** - Neueste Aktivität

### Transportaufschlüsselung

Visuelle Darstellung von:

- **Kreisdiagramm** - Transporttyp-Verteilung
- **Emissionen nach Typ** - CO2 pro Transportmodus
- **Prozentsätze** - Modal-Split-Visualisierung
- **Trends** - Änderungen über Zeit

### Aktivitätsfeed

Eine chronologische Liste von:

- Neue Teilnehmerregistrierungen
- CO2-Daten-Einreichungen
- Statusänderungen
- Systembenachrichtigungen

Jeder Eintrag zeigt:

- Zeitstempel
- Teilnehmername
- Ergriffene Aktion
- Zugehörige Daten

## Live-Ansicht verwenden

### Während der Datensammlung

Best Practices für aktive Überwachung:

#### Regelmäßige Check-ins

- **Morgendliche Überprüfung** - Übernachtaktivität prüfen
- **Mittags-Updates** - Während Spitzenzeiten überwachen
- **Abendzusammenfassung** - Tagesfortschritt überprüfen

#### Engagement-Verfolgung

- **Nicht-Einreicher identifizieren** - Mit Erinnerungen nachfassen
- **Meilensteine feiern** - Teilnahmeziele anerkennen
- **Trends überwachen** - Auf ungewöhnliche Muster achten

### Probleme identifizieren

Achten Sie auf diese Indikatoren:

#### Niedrige Teilnahme

- Einreichungsrate unter Erwartungen
- Viele registriert, aber wenige eingereicht
- **Aktion:** Erinnerungskommunikation senden

#### Bedenken zur Datenqualität

- Ungewöhnlich hohe oder niedrige Entfernungen
- Fehlende Transportinformationen
- **Aktion:** Teilnehmer für Klarstellung kontaktieren

#### Technische Probleme

- Einreichungen erscheinen nicht
- Verbindungsprobleme
- **Aktion:** Systemstatus prüfen, Support kontaktieren

## Live-Ansicht-Funktionen

### Auto-Refresh

Das Dashboard aktualisiert sich automatisch:

- Neue Daten erscheinen ohne Refresh
- Statistiken werden sofort neu berechnet
- Visualisierungen aktualisieren sich reibungslos

### Manueller Refresh

Update erzwingen:

- Klicken Sie auf die **Refresh**-Schaltfläche
- Nützlich, wenn Verbindung unterbrochen wurde
- Stellt sicher, dass Sie die neuesten Daten haben

### Aktuelle Ansicht exportieren

Snapshot herunterladen:

1. Klicken Sie auf die Schaltfläche **"Exportieren"**
2. Format wählen (PNG, PDF, CSV)
3. Für Berichte oder Präsentationen speichern

### Vollbildmodus

Für Präsentationen oder Überwachungsstationen:

- Klicken Sie auf die **Vollbild**-Schaltfläche
- Versteckt Browser-Chrome
- Optimiert Layout für Anzeige

## Die Daten verstehen

### Echtzeit vs Final

Wichtige Unterscheidungen:

- **Live-Daten** - Aktuell in diesem Moment
- **Können sich ändern** - Teilnehmer können Einreichungen aktualisieren
- **Nicht final** - Bis Projekt schließt
- **Für Überwachung** - Nicht offizielle Berichterstattung

### Datenlatenz

Typische Zeitangaben:

- **Einreichungen** - Erscheinen innerhalb von Sekunden
- **Statistiken** - Sofort neu berechnen
- **Visualisierungen** - Reibungslos aktualisieren
- **Bestenlisten** - Automatisch aktualisieren

### Genauigkeit

Live-Ansicht zeigt:

- **Eingereichte Daten** - Wie von Teilnehmern eingegeben
- **Berechnete Emissionen** - Basierend auf Transportfaktoren
- **Aggregierte Gesamtsummen** - Summe aller Einreichungen
- **Können von final abweichen** - Wenn Daten korrigiert werden

## Best Practices

### Für Projektmanager

- **Täglich prüfen** - Über Fortschritt informiert bleiben
- **Mit Team teilen** - Stakeholder auf dem Laufenden halten
- **Für Motivation verwenden** - Fortschritt Teilnehmern zeigen
- **Probleme früh identifizieren** - Probleme prompt ansprechen

### Für Präsentationen

- **Auf Bildschirm projizieren** - Echtzeit-Engagement zeigen
- **Während Meetings teilen** - Teilnahme demonstrieren
- **Meilensteine screenshotten** - Erfolge dokumentieren
- **Für Berichte exportieren** - In Dokumentation einschließen

### Für Analyse

- **Trends beobachten** - Muster über Zeit identifizieren
- **Projekte vergleichen** - Gegen vergangene Events benchmarken
- **Timing optimieren** - Lernen, wann Teilnehmer einreichen
- **Prozesse verbessern** - Basierend auf beobachtetem Verhalten

## Fehlerbehebung

### Verbindungsprobleme

Wenn Live-Ansicht sich nicht verbindet:

- **Internet prüfen** - Verbindung verifizieren
- **Seite aktualisieren** - Neu laden, um neu zu verbinden
- **Status prüfen** - System könnte in Wartung sein
- **Später versuchen** - Temporäre Probleme lösen sich normalerweise

### Daten werden nicht aktualisiert

Wenn Statistiken veraltet erscheinen:

- **Indikator prüfen** - Verifizieren, dass Sie verbunden sind
- **Manueller Refresh** - Refresh-Schaltfläche klicken
- **Projekt verifizieren** - Sicherstellen, dass richtiges Projekt ausgewählt ist
- **Berechtigungen prüfen** - Sie benötigen möglicherweise Zugriffsrechte

### Langsame Leistung

Wenn Live-Ansicht träge ist:

- **Andere Tabs schließen** - Browser-Ressourcen freigeben
- **Datenbereich reduzieren** - Auf kürzliche Aktivität filtern
- **Cache leeren** - Browser-Cache muss möglicherweise geleert werden
- **Export verwenden** - Für detaillierte Analyse anstelle von Live-Ansicht

## Datenschutz und Sicherheit

### Datensichtbarkeit

Live-Ansicht zeigt:

- **Teilnehmernamen** - Wie eingereicht
- **CO2-Daten** - Emissionen und Transport
- **Statistiken** - Aggregierte Metriken
- **Aktivität** - Einreichungszeitstempel

### Zugriffskontrolle

Wer kann Live-Ansicht sehen:

- **Organisationsadministratoren** - Alle Projekte in Organisation
- **Projektkoordinatoren** - Projekte, auf die sie Zugriff haben
- **Teilnehmer** - Können nicht auf Live-Ansicht zugreifen

### Öffentliche Freigabe

Überlegungen für Freigabe:

- **Screenshots** - Können persönliche Daten enthalten
- **Präsentationen** - Anonymisieren, wenn öffentlich geteilt
- **Berichte** - Daten für externe Nutzung aggregieren
- **Einwilligung** - Sicherstellen, dass Teilnehmer Datennutzung zustimmen
