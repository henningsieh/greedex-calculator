# Create Project

Create a new project to start tracking carbon footprint data for your Erasmus+ activity.

## Prerequisites

Before creating a project, ensure:

- You have an active organization
- You have the appropriate permissions (Organization Administrator or Project Coordinator role)

## How to Create a Project

1. Navigate to the **Projects** page
2. Click the **"Create Project"** button
3. Fill in the project details:
   - **Project Name** - A descriptive name for the activity
   - **Description** - Details about the project
   - **Start Date** - When the activity begins
   - **End Date** - When the activity ends
   - **Location** - Where the activity takes place
4. Click **"Create Project"**

## Project Information

### Required Fields

- Project Name
- Start Date
- End Date
- Location

### Optional Fields

- Description
- Project Code (Erasmus+ project number)
- Maximum Participants

## After Creation

Once your project is created:

- You'll be taken to the project details page
- You can start inviting participants
- You can share the participation link
- The project appears in your project list

## Project Status

New projects are created with "Active" status. You can change the status to:

- **Active** - Currently collecting data
- **Completed** - Data collection finished
- **Archived** - Project moved to archive
