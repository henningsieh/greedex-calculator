# Project Details

The Project Details page provides comprehensive information about a specific project, including participant data, carbon footprint statistics, and management tools.

## Accessing Project Details

Navigate to a project's details:

1. Go to the [Projects List](/docs/projects/list)
2. Click on the project name
3. You'll see the project details page with multiple tabs

## Project Details Layout

### Header Section

The top of the page shows:

- **Project name** - Large, prominent title
- **Status badge** - Active, upcoming, completed, or archived
- **Date range** - Start and end dates
- **Location** - Where the activity takes place
- **Quick actions** - Edit, share, archive buttons

### Tab Navigation

Project details are organized into tabs:

#### Overview Tab

Summary information and key metrics:

- Project description
- Key statistics (participants, total CO2)
- Recent activity
- Quick links to other sections

#### Participants Tab

List of all project participants:

- Names and contact information
- Submission status
- Individual carbon footprint data
- Actions per participant

#### Activities Tab

Detailed activity log:

- All carbon footprint submissions
- Transport types and distances
- Submission timestamps
- Data validation status

#### Settings Tab

Project configuration:

- Edit project details
- Manage visibility
- Configure notifications
- Delete project (Owners only)

## Project Information

### Basic Details

#### Project Name

The display name for the project. Can be edited by Owners and Employees.

#### Description

Detailed information about the project:

- Purpose and goals
- Target audience
- Special notes
- Markdown formatting supported

#### Dates

- **Start Date** - When the activity begins
- **End Date** - When the activity ends
- Used for carbon footprint calculations
- Affects project status

#### Location

- **Venue** - Where the activity takes place
- **Address** - Full address for reference
- **Country** - Used for regional statistics

### Project Code

Optional Erasmus+ project number:

- For official project tracking
- Appears in reports
- Useful for grant documentation

## Participant Management

### Viewing Participants

The Participants tab shows:

- **Name** - Participant's full name
- **Email** - Contact email
- **Country** - Origin country
- **Status** - Registration and submission status
- **CO2 Total** - Their calculated carbon footprint

### Participant Statuses

| Status                                        | Description |
| --------------------------------------------- | ----------- |
| **Registered** - Signed up but no submission  |
| **Submitted** - Has submitted carbon data     |
| **Incomplete** - Partial submission           |
| **Confirmed** - Fully registered and complete |

### Adding Participants

Participants are added through:

- [Public participation form](/docs/participation/participate-form)
- Direct invitation (if feature enabled)
- Bulk import (if available)

### Removing Participants

To remove a participant:

1. Find them in the participants list
2. Click the **"Remove"** button
3. Confirm the action

**Note:** This removes their data from the project.

## Carbon Footprint Data

### Total Emissions

The project displays:

- **Total CO2** - Sum of all participant emissions
- **Per-person average** - Average per participant
- **Breakdown by transport** - Plane, train, bus, car percentages

### Transport Types

Emissions are calculated for:

- ✈️ **Plane** - Air travel (highest emissions)
- 🚆 **Train** - Rail travel (low emissions)
- 🚌 **Bus** - Coach/bus travel (medium emissions)
- 🚗 **Car** - Private vehicle (varies by occupancy)

### Data Visualization

Visual representations include:

- Pie chart of transport types
- Bar chart of emissions by country
- Timeline of submissions
- Comparison to benchmarks

## Project Actions

### Edit Project

Modify project details:

1. Click **"Edit"** button
2. Update fields as needed
3. Save changes

Editable fields:

- Name and description
- Dates
- Location
- Project code

### Share Project

Get the participation link:

1. Click **"Share"** button
2. Copy the link
3. Or download QR code

The link format is:

```
/project/[project-id]/participate
```

### Archive Project

Move to archive when complete:

1. Click **"Archive"** button
2. Confirm the action
3. Project moves to archive

Archived projects:

- Are read-only
- Don't appear in active lists
- Can be restored if needed
- Retain all data

### Delete Project

**Warning:** Permanent deletion.

Only Owners can delete projects:

1. Go to Settings tab
2. Click **"Delete Project"**
3. Confirm deletion
4. All data is permanently removed

## Live View

### Real-Time Monitoring

For active projects, access the [Live View](/docs/projects/live-view):

- See submissions as they happen
- Monitor participation rates
- View real-time statistics
- Track leaderboard

Access via:

- **"Live View"** button on project details
- Direct navigation from sidebar

## Project Statistics

### Summary Cards

Key metrics displayed:

- **Total Participants** - Registered count
- **Submission Rate** - % who submitted data
- **Total Emissions** - CO2 in kg
- **Average Distance** - Per participant

### Export Data

Export project data for reporting:

- CSV format for spreadsheets
- PDF for presentations
- JSON for integrations

Export includes:

- Participant information
- Carbon footprint calculations
- Transport breakdowns
- Timestamps

## Troubleshooting

### Can't Access Project

If you can't view a project:

- Verify you're in the correct organization
- Check your role permissions
- Ensure project wasn't deleted
- Try refreshing the page

### Data Not Updating

If statistics seem outdated:

- Data updates may have a short delay
- Check the Activities tab for latest submissions
- Verify participants submitted correctly
- Refresh the page

### Missing Participants

If expected participants don't appear:

- Check if they completed the form
- Verify they used the correct project link
- Look in the Activities tab for partial submissions
- Contact participants to confirm

## Best Practices

### Project Setup

- **Clear names** - Make projects easily identifiable
- **Accurate dates** - Ensures correct status tracking
- **Detailed descriptions** - Help participants understand
- **Correct location** - Affects carbon calculations

### During the Project

- **Monitor daily** - Check submission rates
- **Send reminders** - Follow up with non-submitters
- **Use Live View** - Watch real-time participation
- **Update as needed** - Keep information current

### After Completion

- **Review data** - Check for completeness
- **Export reports** - Save for documentation
- **Archive promptly** - Keep active list clean
- **Analyze results** - Learn for next time
