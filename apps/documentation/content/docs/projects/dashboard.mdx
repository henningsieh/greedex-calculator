# Dashboard

The Dashboard provides a comprehensive overview of your organization's projects, participants, and carbon footprint statistics.

## Dashboard Overview

When you log in to Greendex, the Dashboard is your landing page. It gives you a quick snapshot of your organization's activity and key metrics.

## Dashboard Components

### Organization Header

At the top of the dashboard:

- **Organization name** - Currently active organization
- **Organization switcher** - Change between organizations (if member of multiple)
- **Current date** - Today's date for reference

### Statistics Cards

Key metrics displayed in card format:

#### Total Projects

- Number of active projects
- Quick link to projects list
- Visual indicator of project health

#### Total Participants

- Total participants across all projects
- Breakdown by project (if applicable)
- Growth trends

#### Carbon Footprint

- Total CO2 emissions tracked
- Average per participant
- Comparison to benchmarks

#### Recent Activity

- Latest project updates
- Recent participant submissions
- Upcoming project dates

### Projects Overview

A summary of your projects:

#### Active Projects

- Currently running projects
- Progress indicators
- Quick action buttons

#### Upcoming Projects

- Projects starting soon
- Preparation status
- Participant registration status

#### Recently Completed

- Finished projects
- Final carbon footprint totals
- Archive links

## Dashboard Features

### Real-Time Updates

The dashboard updates automatically:

- New participant submissions
- Project status changes
- Team member updates

### Customization

Planned features include:

- Rearrange dashboard widgets
- Choose which metrics to display
- Set default time ranges

### Quick Actions

Common tasks accessible from the dashboard:

- **Create Project** - Start a new project
- **Invite Team** - Add team members
- **View Reports** - Generate organization reports
- **Settings** - Configure organization

## Understanding the Data

### Project Statuses

| Status    | Description          | Action Needed         |
| --------- | -------------------- | --------------------- |
| Active    | Currently running    | Monitor participation |
| Upcoming  | Starting soon        | Finalize preparations |
| Completed | Finished             | Review and archive    |
| Archived  | Stored for reference | None                  |

### Carbon Footprint Metrics

#### Total Emissions

- Sum of all participant travel emissions
- Measured in kilograms of CO2
- Updated as participants submit data

#### Per-Participant Average

- Total emissions ÷ number of participants
- Useful for benchmarking
- Helps identify high-impact travel

#### Transport Breakdown

- Emissions by transport type
- Plane, train, bus, car percentages
- Identifies improvement opportunities

## Best Practices

### Daily Use

- **Check in morning** - Review overnight activity
- **Monitor active projects** - Ensure participation is on track
- **Follow up** - Contact participants who haven't submitted

### Weekly Review

- **Analyze trends** - Look for patterns in the data
- **Compare projects** - See which are performing well
- **Plan ahead** - Prepare for upcoming projects

### Monthly Reporting

- **Export data** - Generate reports for stakeholders
- **Review goals** - Check against carbon reduction targets
- **Adjust strategies** - Based on what's working

## Troubleshooting

### Dashboard Not Loading

If the dashboard doesn't appear:

- Check your internet connection
- Verify you're logged into the correct organization
- Try refreshing the page
- Clear browser cache if persistent

### Data Seems Outdated

If statistics don't match expectations:

- Data updates may be delayed slightly
- Check individual project pages for latest data
- Verify participants have submitted their data

### Missing Projects

If projects don't appear:

- Check the Projects page for full list
- Verify project permissions
- Ensure you're in the correct organization
- Check if projects are archived
