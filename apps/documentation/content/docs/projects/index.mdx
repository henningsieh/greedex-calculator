# Projects

Projects represent individual Erasmus+ activities (youth exchanges, training courses, meetings) that you want to track carbon footprint data for.

## What is a Project?

A project in Greendex contains:

- **Project Details** - Name, description, dates, location
- **Participants** - People attending the activity
- **Carbon Data** - Travel information and emissions calculations
- **Status** - Active, completed, or archived

## Project Lifecycle

1. **Create** - Set up a new project with basic information
2. **Invite** - Add participants to the project
3. **Collect** - Gather carbon footprint data from participants
4. **Monitor** - Track submissions in real-time
5. **Archive** - Close the project when complete

## Project Types

Greendex supports tracking carbon footprint for various Erasmus+ activities:

- Youth Exchanges
- Training Courses
- Networking Meetings
- Job Shadowing
- Volunteering Activities
