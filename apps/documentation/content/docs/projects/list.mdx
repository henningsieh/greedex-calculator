# Project List

The Projects page provides a comprehensive view of all your organization's projects, allowing you to manage, search, and filter projects efficiently.

## Accessing the Project List

Navigate to the Projects page:

1. Click **"Projects"** in the main sidebar
2. You'll see a table of all your projects
3. Use the controls to filter and sort

## Project List Layout

### Table Columns

The projects table displays:

| Column           | Description                              |
| ---------------- | ---------------------------------------- |
| **Name**         | Project name with status indicator       |
| **Dates**        | Start and end dates                      |
| **Location**     | Where the activity takes place           |
| **Participants** | Number of registered participants        |
| **Status**       | Active, upcoming, completed, or archived |
| **Actions**      | Quick action buttons                     |

### Status Indicators

Each project has a visual status indicator:

- 🟢 **Active** - Currently running
- 🟡 **Upcoming** - Starting within 30 days
- 🔵 **Completed** - Finished, data collection done
- ⚪ **Archived** - Stored for reference

## Filtering and Sorting

### Search

Use the search box to find projects by:

- Project name
- Location
- Description keywords

### Filters

Filter projects by:

#### Status Filter

- All Projects
- Active only
- Upcoming
- Completed
- Archived

#### Date Range

- Projects starting after a date
- Projects ending before a date
- Custom date ranges

#### Location

- Filter by country or city
- Useful for regional reporting

### Sorting

Click column headers to sort:

- **Name** - Alphabetical order
- **Dates** - Chronological order
- **Participants** - By participant count
- **Created** - When the project was added

Toggle between ascending and descending order by clicking again.

## Project Actions

### View Project

Click on a project name to:

- View detailed project information
- See participant list
- Access project settings
- View carbon footprint data

### Quick Actions

Each project row has action buttons:

#### Edit

- Modify project details
- Change dates or location
- Update description

#### Share

- Copy participation link
- Download QR code
- Share via email

#### Archive

- Move completed projects to archive
- Keeps data but hides from active list
- Can be restored later

### Bulk Actions

Select multiple projects to:

- Archive multiple at once
- Export data for selected projects
- Generate combined reports

## Creating New Projects

### Create Project Button

Click **"Create Project"** to start a new project:

- Button appears in the page header
- Only visible to Organization Administrators and Project Coordinators
- Opens the project creation form

See [Create Project](/docs/projects/create) for detailed instructions.

## Empty States

### No Projects

If your organization has no projects:

- You'll see a welcome message
- Quick link to create your first project
- Tips for getting started

### No Matching Results

If filters return no results:

- Clear filters to see all projects
- Adjust search terms
- Check if projects exist in other statuses

### Trends

Visual indicators show:

- Project growth over time

## Best Practices

### Organization

- **Use consistent naming** - Makes searching easier
- **Add clear descriptions** - Helps team members understand
- **Set realistic dates** - Ensures accurate tracking
- **Archive promptly** - Keep active list manageable

### Regular Maintenance

- **Weekly review** - Check active project status
- **Monthly cleanup** - Archive completed projects
- **Quarterly audit** - Review all project data
- **Annual export** - Backup project information

### Team Collaboration

- **Share project links** - Make it easy for participants
- **Update regularly** - Keep project info current
- **Monitor participation** - Follow up on low submission rates

## Troubleshooting

### Projects Not Appearing

If you can't see expected projects:

- Check filter settings
- Verify you're in the correct organization
- Ensure projects weren't archived
- Check your role permissions

### Can't Create Projects

If the create button is missing:

- You may have Participant role only
- Contact an Organization Administrator or Project Coordinator for access
- Check if you've reached project limits

### Slow Loading

If the project list loads slowly:

- Try clearing filters
- Reduce date range
- Check your internet connection
- Contact support for large datasets
