# Projekt erstellen

Erstellen Sie ein neues Projekt, um mit der Verfolgung von CO2-Fußabdruck-Daten für Ihre Erasmus+-Aktivität zu beginnen.

## Voraussetzungen

Bevor Sie ein Projekt erstellen, stellen Sie sicher:

- Sie haben eine aktive Organisation
- Sie haben die entsprechenden Berechtigungen (Eigentümer- oder Mitarbeiter-Rolle)

## Wie man ein Projekt erstellt

1. Navigieren Sie zur **Projekte**-Seite
2. Klicken Sie auf die Schaltfläche **"Projekt erstellen"**
3. Füllen Sie die Projektdetails aus:
   - **Projektname** - Ein beschreibender Name für die Aktivität
   - **Beschreibung** - Details zum Projekt
   - **Startdatum** - Wann die Aktivität beginnt
   - **Enddatum** - Wann die Aktivität endet
   - **Standort** - Wo die Aktivität stattfindet
4. Klicken Sie auf **"Projekt erstellen"**

## Projektinformationen

### Erforderliche Felder

- Projektname
- Startdatum
- Enddatum
- Standort

### Optionale Felder

- Beschreibung
- Projektcode (Erasmus+-Projektnummer)
- Maximale Teilnehmer

## Nach der Erstellung

Sobald Ihr Projekt erstellt ist:

- Sie werden zur Projektdetails-Seite gebracht
- Sie können mit der Einladung von Teilnehmern beginnen
- Sie können den Teilnahmelink teilen
- Das Projekt erscheint in Ihrer Projektliste

## Projektstatus

Neue Projekte werden mit "Aktiv"-Status erstellt. Sie können den Status ändern zu:

- **Aktiv** - Sammelt derzeit Daten
- **Abgeschlossen** - Datensammlung beendet
- **Archiviert** - Projekt in Archiv verschoben
