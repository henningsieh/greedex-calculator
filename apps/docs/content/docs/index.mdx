# Introduction

Welcome to the Greendex documentation. This site contains comprehensive documentation
for the Greendex Carbon Footprint Calculator.

## What is Greendex?

Greendex is a specialized carbon footprint calculator designed for Erasmus+ youth exchanges,
training courses, and meetings. It helps organizations track and reduce their environmental
impact by calculating CO2 emissions from travel and other activities.

## Key Features

- **Organization Management**: Create and manage organizations with team members
- **Project Tracking**: Create projects for different Erasmus+ activities
- **Participant Management**: Track participants and their carbon footprint data
- **Real-time Monitoring**: Live view dashboard for monitoring participation
- **Public Participation**: Allow participants to submit their travel data via public forms
