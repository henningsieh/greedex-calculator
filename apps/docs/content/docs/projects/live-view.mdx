# Live View

The Live View provides real-time monitoring of active projects, showing participant submissions, carbon footprint statistics, and engagement metrics as they happen.

## What is Live View?

Live View is a dashboard for project organizers to:

- **Monitor participation** in real-time
- **Track carbon data submissions** as they arrive
- **View statistics updates** instantly
- **See participant engagement** metrics
- **Identify trends** during the data collection period

## Accessing Live View

### From Project Details

1. Go to a project's details page
2. Click the **"Live View"** button
3. The live dashboard opens

### From Sidebar

If Live View is enabled for your organization:

1. Look for **"Live View"** in the sidebar
2. Click to access the dashboard
3. Select the project to monitor

## Live View Components

### Real-Time Indicator

A visual indicator shows:

- 🟢 **Live** - Connected and receiving updates
- 🟡 **Connecting** - Establishing connection
- 🔴 **Disconnected** - Connection lost, attempting reconnect

### Stats Overview

Key metrics displayed in real-time:

#### Total Participants

- Current number of registered participants
- Updates as new people join
- Shows growth trend

#### Submission Rate

- Percentage who submitted carbon data
- Updates with each new submission
- Target indicator for goals

#### Total CO2 Emissions

- Running total of all emissions
- Updates immediately on new submissions
- Shows comparison to projections

#### Average per Participant

- Mean carbon footprint
- Updates with each submission
- Helps identify outliers

### Leaderboard

A ranked list showing:

- **Top participants** by various metrics
- **Countries represented** - Origin of participants
- **Transport choices** - Most popular methods
- **Recent submissions** - Latest activity

### Transport Breakdown

Visual representation of:

- **Pie chart** - Transport type distribution
- **Emissions by type** - CO2 per transport mode
- **Percentages** - Modal split visualization
- **Trends** - Changes over time

### Activity Feed

A chronological list of:

- New participant registrations
- Carbon data submissions
- Status changes
- System notifications

Each entry shows:

- Timestamp
- Participant name
- Action taken
- Associated data

## Using Live View

### During Data Collection

Best practices for active monitoring:

#### Regular Check-ins

- **Morning review** - Check overnight activity
- **Midday updates** - Monitor during peak times
- **Evening summary** - Review day's progress

#### Engagement Tracking

- **Identify non-submitters** - Follow up with reminders
- **Celebrate milestones** - Acknowledge participation goals
- **Monitor trends** - Watch for unusual patterns

### Identifying Issues

Watch for these indicators:

#### Low Participation

- Submission rate below expectations
- Many registered but few submitted
- **Action:** Send reminder communications

#### Data Quality Concerns

- Unusually high or low distances
- Missing transport information
- **Action:** Contact participants for clarification

#### Technical Issues

- Submissions not appearing
- Connection problems
- **Action:** Check system status, contact support

## Live View Features

### Auto-Refresh

The dashboard automatically updates:

- New data appears without refresh
- Statistics recalculate instantly
- Visualizations update smoothly

### Manual Refresh

Force an update:

- Click the **refresh** button
- Useful if connection was interrupted
- Ensures you have latest data

### Export Current View

Download a snapshot:

1. Click **"Export"** button
2. Choose format (PNG, PDF, CSV)
3. Save for reports or presentations

### Full-Screen Mode

For presentations or monitoring stations:

- Click **fullscreen** button
- Hides browser chrome
- Optimizes layout for display

## Understanding the Data

### Real-Time vs Final

Important distinctions:

- **Live data** - Current as of this moment
- **May change** - Participants can update submissions
- **Not final** - Until project closes
- **For monitoring** - Not official reporting

### Data Latency

Typical timing:

- **Submissions** - Appear within seconds
- **Statistics** - Recalculate immediately
- **Visualizations** - Update smoothly
- **Leaderboards** - Refresh automatically

### Accuracy

Live View shows:

- **Submitted data** - As entered by participants
- **Calculated emissions** - Based on transport factors
- **Aggregated totals** - Sum of all submissions
- **May differ from final** - If data is corrected

## Troubleshooting

### Connection Issues

If Live View won't connect:

- **Check internet** - Verify your connection
- **Refresh page** - Reload to reconnect
- **Check status** - System may be under maintenance
- **Try later** - Temporary issues usually resolve

### Data Not Updating

If statistics seem stale:

- **Check indicator** - Verify you're connected
- **Manual refresh** - Click refresh button
- **Verify project** - Ensure correct project is selected
- **Check permissions** - You may need access rights

### Slow Performance

If Live View is sluggish:

- **Close other tabs** - Free up browser resources
- **Reduce data range** - Filter to recent activity
- **Clear cache** - Browser cache may need clearing
- **Use export** - For detailed analysis instead of live view

## Privacy and Security

### Data Visibility

Live View shows:

- **Participant names** - As submitted
- **Carbon data** - Emissions and transport
- **Statistics** - Aggregated metrics
- **Activity** - Submission timestamps

### Access Control

Who can see Live View:

- **Owners** - All projects in organization
- **Employees** - Projects they have access to
- **Participants** - Cannot access Live View

### Public Sharing

Considerations for sharing:

- **Screenshots** - May contain personal data
- **Presentations** - Anonymize if sharing publicly
- **Reports** - Aggregate data for external use
- **Consent** - Ensure participants consent to data use
