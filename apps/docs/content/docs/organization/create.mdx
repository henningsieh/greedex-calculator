# Create Organization

Creating an organization is the first step after verifying your email. Organizations represent your legal entity (company, NGO, institution) that runs Erasmus+ projects.

## When to Create an Organization

You'll be prompted to create an organization:

- Immediately after email verification
- When logging in without any existing organizations
- If you leave all organizations and need to create a new one

## Organization Creation Process

### Step 1: Access the Creation Form

After login, if you have no organizations:

- You'll be automatically redirected to the organization creation page
- The page shows a simple form to get started

### Step 2: Enter Organization Details

Fill in the required information:

#### Organization Name (Required)

- Enter the official name of your organization
- This name will be visible to team members and participants
- You can change this later in settings

#### Organization Slug (Auto-generated)

- A URL-friendly version of your name
- Used in some URLs and references
- Usually auto-generated from the name

### Step 3: Submit the Form

Click **"Create Organization"** to complete the setup.

## What Happens Next

After creating your organization:

1. **Organization created** - Your organization is now active
2. **You're the Owner** - You have full control over the organization
3. **Redirect to Dashboard** - You'll be taken to your organization dashboard
4. **Ready to invite team** - You can now add members

## Organization Limits

### Single Organization Per User

Currently, each user account is associated with one organization at a time through membership. You can:

- Be a member of multiple organizations (via invitations)
- Switch between organizations you belong to
- Create additional organizations if needed

### Ownership

As the creator:

- You automatically become the **Owner**
- You can invite other Owners, Employees, or Participants
- You can transfer ownership to another member
- You can delete the organization if needed

## Troubleshooting

### "Organization Already Exists"

If you see this error:

- The organization name may already be taken
- Try a different, more specific name
- Add location or department to make it unique

### Form Won't Submit

- Ensure the organization name is filled in
- Check for any validation errors
- Try refreshing the page and trying again

### Redirected Back to Create Page

If you're redirected back after creation:

- The organization may not have been created successfully
- Check your network connection
- Try creating the organization again

## Best Practices

### Choosing an Organization Name

- **Use official name** - Match your legal entity name
- **Be specific** - Include location if you have multiple chapters
- **Keep it professional** - This name is visible to participants
- **Avoid abbreviations** - Unless they're widely recognized

### Setting Up Your Organization

After creation, consider:

1. [Invite team members](/docs/organization/invitations) to help manage
2. [Configure settings](/docs/organization/settings) like timezone
3. [Create your first project](/docs/projects/create)
4. Set up branding and customizations

## Multi-Organization Users

If you belong to multiple organizations:

### Switching Organizations

1. Use the organization switcher in the sidebar
2. Select the organization you want to work with
3. Your dashboard and projects update automatically

### Organization Context

- All actions are performed in the context of the active organization
- Projects, participants, and team members are organization-specific
- Settings apply to the currently selected organization
